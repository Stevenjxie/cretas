// 真实场景 (已脱敏)

一家做卤制品 / 熟食的非标食品加工厂。负责人是资深 ERP 设计者，曾在大型连锁集团主导 ERP——这已经是他第 4 次上 ERP 系统。前三次都因为"标品 ERP 套不进非标生产"而失败：没有固定产线、原料一锅多出、一个产品涉及几十种原辅料，一线工人还普遍年纪偏大。

痛点 → 方案

标品 ERP 装不下的，我们一条条接住

// 01 防呆易用

不依赖人，系统替他兜底

把出错挡在发生之前，而不是出错后报错。一线工人不用培训、不用记规则。

  • 入库直接显示「本次该收多少」，超限挡住
  • 每个操作都带品名、单号、责任人，不会做串
  • 写操作防重复提交，不会重复建单

// 02 非标生产

没有固定产线，照样管得住

不强行套"一产线、二产线"。组长动态认领工序，边做边累积报工，符合非标加工的真实节奏。

  • 报工按工序维度，不是按固定产线
  • 组长 / 班组动态认领当前工序
  • 第二小时、第三小时累积上报，不必等结束

// 03 复杂 BOM

一个产品几十种料，分层管清

原料、辅料、包材分层管理，再多也不糊；改配方有痕迹，出成率提前预览。

  • 原料 / 辅料 / 包材 三层拆分，40+ 料也清晰
  • 物料变更全程留痕
  • 出成率提前预览，克 ↔ 千克自动换算

// 04 批次追溯 · 先进先出

每一批料，从原料到成品查得到

出库可选批次、新货老货分得清，PC 生产批次 + 先进先出，全链路批次血缘可正查反查。

  • 出库手动选批次，不再默认乱发
  • PC 生产批次 + 先进先出（FIFO）推荐
  • 从成品倒查到原料，每一段都留痕

// 05 双仓流转

总仓 + 线边仓，流转不乱

线边仓当天清零、总仓统一调度，反向调拨自动生成草稿，销售统一从总仓发货。

  • 总仓 / 线边仓分开，库存清晰
  • 反向调拨自动生成草稿单
  • 销售出库统一从总仓走，不串仓
双仓 · 调拨
仓间流转
→总仓 → 线边仓（领料）自动
←线边仓 → 总仓（成品回库）草稿生成
↗总仓 → 客户（发货）统一出口
// 06 全链路打通

下单 → 生产 → 出库 → 开票，一条线

生产计划关联销售订单，成本抓得起来；开票按税率分组、出库金额联动、发票回传。

  • 生产计划关联订单，成本可归集
  • 开票按税率分组（原料 9% / 加工费 13%）
  • 出库金额联动开票，财务对得上；发票附件回传
