## A. Top 3 ⭐⭐⭐ 必抄（最高 ROI）

### A-1. 业务流程图导航（顶部可点击节点） ⭐⭐⭐
- **宏见做法**：每个模块顶部有"节点流程图"——粉色=待处理 / 绿色=进行中 / 蓝色=已完成。点击节点跳对应单据列表。
- **HD 帧证据**：`000043` 销售订单工作流图 / `001333` 采购流程图 / `001736` 财务流程图（5 张流程图卡片 page）
- **Cretas 现状**：❌ **完全无** WorkflowVisualizer 组件
- **Cretas 怎么用**（核心创新点）：
  - **移动 App**：放在首页 BentoGrid 顶部一个 1x2 大卡片，显示"今日工作流状态" + 3-5 个节点 + 数量徽章
  - **Web-Admin**：每个业务模块（销售/采购/生产）顶部加 horizontal flowchart bar
  - **AI 增强**：节点支持"AI 触发"——点节点 + 一句话即可（AIChat 进入该节点 context）
- **工作量**：组件抽象 5d / 5 模块接入 5d = **10 人天**
- **战略意义**：**onboarding 新员工神器** + 替代传统左侧菜单的认知方式

### A-2. 行末"操作 ▾" 下拉收纳次要动作 ⭐⭐⭐
- **宏见做法**：列表行末一个"操作 ▾"按钮，点开 8-14 个次要动作（转生产/转外购/退货/调拨/打印/复制/锁定 / ...）。**主行只显示 4-6 个 chip 状态**。
- **HD 帧证据**：`000122` 物料需求页 + `001435` 库存查询 + `001151` 销售订单 — 所有列表都这么做
- **Cretas 现状**：⚠️ 移动端用 long press / swipe 但 8+ 选项 BottomSheet 未抽象；Web-Admin 散用
- **Cretas 怎么用**：
  - **移动 App**：长按行 → BottomSheet 显示 8-10 个动作（已有 gesture handler，缺统一抽象）
  - **Web-Admin**：抽 `<RowActionMenu items={[]}/>` 组件
  - **AI 增强**：BottomSheet 顶部有「跟 AI 说」入口——"我要把这单转成生产"
- **工作量**：移动 BottomSheet 抽象 3d / Web RowActionMenu 3d / 8 列表接入 4d = **10 人天**
- **战略意义**：列表行不再拥挤，状态 chip + 动作下拉分离

### A-3. Sticky Footer 实时合计 + 分页同栏 ⭐⭐⭐
- **宏见做法**：列表底部固定栏一行显示 `共 3 条 [1/3] 总金额: ¥6,525 总数量: 122 总损耗: 5.2%`，跟分页器同栏
- **HD 帧证据**：`000949` 销售单底部 + `000745` 物料需求底部
- **Cretas 现状**：❌ **完全无** StickyFooterSummary 抽象
- **Cretas 怎么用**：
  - **移动 App**：列表底部 50px sticky bar（已有 SafeAreaView 基础）
  - **Web-Admin**：列表分页器升级为 `<TableFooter>` 含 stats
  - **AI 增强**：sticky bar 上一个图标点击 → AIChat "给我这页的统计分析"
- **工作量**：StickyFooterSummary 抽象 3d / 10 列表接入 4d = **7 人天**
- **战略意义**：财务/运营录入时**实时校验数据正确性**

## F. 关键示意（怎么改 Cretas）

### F-1. 业务流程图导航 — 在哪用？

**移动 App** — 首页 BentoGrid 加新卡片类型：

```
┌────────────────────────────────────────┐
│  📊 今日销售工作流          [3 待办]    │
│                                          │
│  [⭕ 待审 5] → [🟢 进行 3] → [✅ 完成 12]│
│   ↑ 点击进入                              │
└────────────────────────────────────────┘
```

**Web-Admin** — 业务模块顶部 horizontal bar：

```
┌─────────────────────────────────────────┐
│  销售管理 / 销售订单                       │
├─────────────────────────────────────────┤
│ ⭕ 待审 (5) → 🟢 进行 (12) → ✅ 完成 (87)│
├─────────────────────────────────────────┤
│  [当前列表显示在这]                       │
└─────────────────────────────────────────┘
```

**移动 App** — 列表卡片长按：

## G. 战略融合 (Cretas 现代 + 宏见传统)

最终 Cretas UI/UX 设计语言（取两家所长）：

| 维度 | 选哪家 | 理由 |
|---|---|---|
| 整体设计语言 | Cretas Neo Minimal | 现代趋势，配色优雅 |
| 移动端导航 | Cretas Bento Grid + BottomTab | 角色分离 + 触感友好 |
| Web-Admin 导航 | **借鉴宏见累积 Tab + Cretas 配色** | 复杂场景多任务并行 |
| 列表行设计 | **借鉴宏见 chip + 操作下拉 + Cretas 圆角间距** | 信息密度 + 视觉舒适 |
| 表单 | **Cretas Formily AI-First** | 客户主诉求 |
| 弹窗 | Cretas BottomSheet 抽象（统一） | 移动友好 |
| 状态反馈 | **借鉴宏见 Skeleton + Toast + Cretas 配色** | 现代体验 |
| 状态可视化 | **借鉴宏见流程图 + Cretas 卡片** | onboarding 友好 |
| AI 增强 | **Cretas AIChat + 钉钉机器人** | 客户原话 |
| 微交互 | **Cretas Haptic 补充 + 长按 BottomSheet** | 触感优先 |

## I. 元层认知

1. **不要全抄**：宏见 PC Web 范式有 30% 不适合移动端
2. **AI 增强是 Cretas 独家**：每个借鉴模式都加"AI 触发"入口（行末下拉顶部「跟 AI 说」/ sticky footer「📊 AI 分析」/ 流程节点「AI 进入」）
3. **Cretas 现代设计是优势**：不要为了对齐宏见放弃 Neo Minimal
4. **角色化 UI 已经领先**：10 角色独立 Navigator 是宏见做不到的
5. **Bento Grid + 流程图导航融合**：这是创新点——首页 Bento 卡片中放流程图，融合两家所长
