# F006 生产全链路测试 SOP（2026-07-19）

> 适用范围：食品工厂的建档、BOM、Workflow、期初库存、采购、生产计划、调拨、报工、结单、成本、销售交付与盘点。本文是操作咨询口径，不代替页面权限、审批规则或正式业务单据。
>
> 在线逐项核对版：`https://aiassist.cretaceousfuture.com/lsmsop/`

## 1. 回答与执行边界

- AI Assist 只解释功能、字段、路径、业务逻辑、测试步骤与排错方法，不代替用户创建、审批、报工、调库存或结单。
- 不确定当前页面是否支持某入口时，明确写“请以当前页面为准并记录为待验证”，不能编造按钮、状态或成功结果。
- 回答操作问题时优先给出：适用路线、菜单路径、填写内容、操作步骤、预期结果、阻塞条件。
- 销售订单生产与存货生产共用 SKU、BOM、Workflow、报工、成本和仓储能力，但生产计划来源、结单与销售交付不同。

## 2. 三种测试深度

### MVP：非阻塞最小闭环

只走正常数据：主数据建档 → 一条可用 Workflow → 期初库存 → 一条生产路线 → 正式报工 → 必要审批 → 仓库确认入库 → 成本与盘点。先证明链路能闭环，不故意制造异常。

### 中度：关键业务闭环

包含全部 MVP，再加入 1→1、多→1、1→多、多→多基础拓扑、缺料采购、报工审批、完整调拨、部分发货、开票收款和关键成本分摊。

### 全量：全数据闭环

包含全部中度，再加入 Workflow 覆盖冲突、采购异常、质检、不良、退料报损、撤回冲销、BOM/ECN 版本治理、跨单合并和分析核对。

## 3. MVP 前置条件

1. 确认当前账号、工厂和角色正确；至少有一个生产仓及一个主仓或外仓。
2. 确认生产操作员、生产主管、仓管能进入各自页面。
3. 中度以上再准备采购、销售、财务与审批角色；全量再准备质检、BOM/ECN、损耗与冲销角色。
4. 系统管理 → 系统设置 → 成本设置：核对全局工时单价。工序主档不重复填写本轮工时和时薪；实际工时在工序报工时记录。

## 4. 创建投入物料档案

菜单路径：系统管理 → 原料类型字典。

- 原料、辅料、包材都在原料类型字典创建，不在 SKU 管理中创建。
- 建议测试数据统一加前缀。例：原料 A/B/C/D，黄油调味料、香辛料，成品盒、封膜、外箱。
- 原料 A/B/C/D 入库计量单位使用 kg；按页面选择 L1 大类、L2 中类、L3 小类。
- 保存后应能按名称搜索，且同名对象只出现一次；辅料和包材应能在 BOM 对应页签中被筛选。

## 5. 创建半成品与成品 SKU

菜单路径：生产管理 → 生产配置 → 产品管理。

### 半成品 SKU

- 产品大类选择半成品，基本单位选择 kg。
- 半成品只定义库存与报工单位，不在 SKU 主档预设投入多少必然产出多少。

### 成品 SKU

- 产品大类选择成品，基本单位选择盒。
- 标准单位换算填写 `1盒=800克`；需要外箱时再增加 `1箱=8盒`。
- 规格文本由系统根据单位关系生成，不再手写另一套口径。
- 盒、克、箱各司其职：不能显示成 `1kg=1盒`、`1袋=1盒` 或把外箱右侧单位改成 kg。
- SKU 单位改变后，Workflow 应提示重新核对并发布；已创建生产计划继续使用创建时快照，不回写历史。

## 6. 创建工序主数据

菜单路径：生产管理 → 生产配置 → 工序管理 → 新增工序。

- 原料处理：填写工序名称、工序类别，默认产出类型选择半成品。
- 定量包装：默认产出类型选择成品。
- 工序主档不维护 kg、盒或 1:1 数量换算；投入单位和产出单位由 SKU 与 Workflow 的连接关系决定。
- 预估工时、标准时薪和出成率上下限属于高级设置，本轮不是必填；实际工时在报工中记录。

## 7. 创建、按工序配置并激活 BOM / 配方

菜单路径：生产管理 → 生产配置 → BOM / 配方维护。

1. 选择目标成品 SKU，先核对基本单位和标准克重由 SKU 只读带入。SKU 缺标准克重时先回产品管理补录。
2. 原料页签：逐行添加主原料，单位由物料主档带入；普通原料不在这里硬写固定出成率。
3. 包材页签：填写每一个成品基本单位所需包材量。例如 1 盒用 1 个盒；8 盒共用 1 箱时，每盒外箱用量为 0.125。
4. 至少有一行原料或包材后创建配方头草稿；配方头的盒和 800g/盒为只读，不另写换算。
5. 辅料 → 工序编排：选择草稿版本，展开具体工序，添加工序调料。填写每生产 1kg 本道半成品所需辅料量、单位及是否计入成本。
6. 只有真实存在首锅/续锅差异的辅料才开启按锅序计算；第一锅 100%，后续锅填写相对第一锅比例。
7. 在辅料汇总中核对辅料使用工序、g/kg、锅序、自动单价和计成本标记，避免重复计成本。
8. 激活版本。同一 SKU 只能有一个 ACTIVE；修改生效版本时复制为新草稿，审核后再激活。旧计划继续引用原快照。

常见阻塞：SKU 无标准克重、无原料/包材行、同一物料重复、单位量纲不兼容、辅料未绑定工序、历史版本达到上限、试图直接编辑生效版本。

## 8. 绘制、校验并发布 Workflow

菜单路径：生产管理 → 生产配置 → 产品-工序配置 → 选择归属 SKU。

1. 成品归属主路线：顶部归属选择目标成品；最终成品 Cell 必须与顶部归属一致。
2. 原料归属分流或联产路线：顶部归属选择真实原料，画布可包含多个终端成品；不能伪造产品 SKU 作为归属。
3. 建立链路：原料 Cell A/B/C/D → 原料处理工序 → 处理后半成品 Cell → 定量包装工序 → 成品 Cell。
4. 同一张 Workflow 里同一原料只能选择一次；已选原料应从后续选择器中消失。
5. 多个来源连接到同一工序后，系统自动理解为“批次自由选择，至少 1 个”。不再配置替代组、全部必投、主投入或追加投入。
6. 原料和处理后半成品均为 kg，最终成品为盒。Workflow 只声明每项投入和产出的报工单位，不预设 kg 必然产多少盒。
7. 自动布局后检查无悬空线、无重复原料、Cell 均绑定 SKU，保存草稿并发布启用。

## 9. 生产计划选品与 Workflow 匹配

Workflow 冲突在创建生产计划并选择成品时出现，不是在绘制 Workflow 时出现。系统以“用户所选成品集合”和“Workflow 终端成品集合”匹配；Workflow 名称不参与优先级。

### 四种基础拓扑

- 1→1：选择唯一成品，唯一完全匹配路线自动固定。
- 多→1：多个原料汇入同一成品。计划选该成品时固定路线；报工至少选择一个来源，可选择一个、多个或全部。
- 1→多：一个来源联产多个成品。选择全部终端时完全匹配；只选其中一部分时，唯一最小超集可被选中，但必须提示会同时产出其他成品并要求确认。
- 多→多：多个来源联产多个成品。选择完整终端集合时完全匹配；只选子集时按最小超集处理并明确额外产出。

### 覆盖冲突处理

1. 优先完全匹配：终端集合与用户选择完全相等。
2. 没有完全匹配时，选择包含用户所选成品的最小超集。
3. 同一层级仍有多个候选时弹出 Workflow 选择弹窗，禁止按名称、创建时间或归属类型静默猜测。
4. 每个候选应提供工序链预览，展示原料、半成品、工序和成品 Cell 的连接关系；用户离开预览按钮后气泡关闭。
5. 找不到覆盖全部所选成品的单条路线时明确阻止，不自动拼接多张 Workflow。

## 10. 期初库存、采购与生产前调拨

### 期初库存

菜单路径：仓储管理 → 入库管理或原料批次。

- 按物料、仓库、批次、数量、单位、生产/到期日期、单价录入期初库存。
- 原料、辅料、包材分别入库；入库单位必须与主档兼容。
- 保存后在分仓库存查询中回读批次、可用量和金额。

### 缺料采购

菜单路径：采购管理 → 采购订单。

- 创建采购订单 → 提交 → 审批 → 到货登记 → 质检或收货 → 仓库确认入库。
- 未审批订单、未确认到货或质检不合格不能增加可用库存。

### 主仓/外仓到生产仓

- 创建领料或仓间调拨，源仓选择主仓/外仓，目标仓选择生产仓。
- 提交、审批、发运、签收、确认后，源仓减少、生产仓增加；同厂总库存保持守恒。
- 库存不足、批次状态不允许、源目标仓相同或单位不兼容时必须阻止。

## 11. 创建生产计划

### 存货生产

菜单路径：生产管理 → 生产计划 → 新建。

- 来源选择存货生产，选择一个或多个目标成品、计划数量、日期和仓库。
- 系统按成品集合匹配 Workflow；唯一候选自动固定，冲突候选必须人工选择并查看工序预览。
- 计划启动前固定 SKU、BOM 与 Workflow 版本快照。

### 销售订单生产

菜单路径：销售管理 → 销售订单 → 新建，随后确认并按当前规则完成财务审核或审批。

- 订单包含客户、成品 SKU、数量、单价和交付日期。
- 审核通过后从订单生成或关联生产计划；生产计划必须回溯订单号和订单行。
- 缺料时形成采购或补货动作，不允许绕过库存与审批直接开工。

## 12. 逐道报工

菜单路径：生产管理 → 报工或移动端工序操作。

每道工序至少核对以下输入：生产计划、工序、操作人员、开始/结束或实际工时、投入物料及批次、投入数量、合格产出、不良/损耗、产出批次、备注和凭证。

- 多来源工序：至少选择一个投入来源；允许选一个、多个或全部，未选来源不能被扣库存。
- 单一确定来源：系统自动锁定，不展示没有意义的多选控件。
- 多产出工序：选择并填写本次真实产出的成品；未选择的联产品不得入库。
- 副产物：在具体报工记录的副产字段填写，不要求为了副产物单独建 Workflow。副产物数量与回收价值分别记录。
- 锅序：只有 BOM 对本道工序的辅料开启锅序时显示锅数或锅序计算；普通辅料不显示。
- 人工成本：按本道实际工时 × 全局工时单价计算，不读取工序主档中的测试时薪。
- 报工提交、审批、正式落账分开。草稿、待审、驳回状态不能提前改变正式库存与成本。

常见报错：库存不足、没有可用批次、批次过期或被锁定、投入未至少选择一项、投入数量超过可用量、产出单位不匹配、Workflow/BOM 快照缺失、重复提交、无报工权限。

## 13. 小结、结单与仓库确认入库

### 存货生产

- 每轮报工后可做增量小结：只扣本轮投入、只增加本轮产出，计划继续开放。
- 第二次小结只处理第二轮增量，不能重复扣减第一轮。
- 所有轮次完成后停产，计划关闭且不能继续小结。

### 销售订单生产

- 打开核对结单，核对实际产量、领用、工时、成品单位和销售订单关联。
- 提交结单只表示生产方完成交接，不等于仓库已经收货。

### 仓库确认完工入库

- 仓管核对计划号、成品 SKU、批次、生产日期、应收/实收数量、单位、目标生产仓和差异原因。
- 只有仓库确认成功后，正式成品批次和生产仓可用库存才生效；重复确认不能重复入库。

## 14. 生产后仓储交接

- 先在生产仓确认正式成品批次，再创建生产仓 → 主仓/外仓的仓间调拨。
- 调拨依次完成申请、审批、发运、签收和入库；确认后源仓减少、目标仓增加、同厂总库存不变。
- 少收时记录调拨差异，未处理前不能静默平账；发出量 = 实收量 + 在途量 + 已审批损耗量。
- 余料退回必须沿用原领料批次与成本；损耗须填原因、责任环节与凭证并按规则审批。

## 15. 成本归集与出厂核算

- 成本汇总与盘点是两条不同链路。
- 逐工序核对投入、产出、人数、实际工时、人工成本、材料成本和小计。
- 多产出工序的成本分摊比例合计必须为 100%，各产出分摊成本之和等于本道应分成本。
- 副产回收 = 副产数量 × 回收单价；净成本 = 总成本 − 副产回收。副产无单价时数量仍显示，回收额为 0。
- 成品出厂成本应能解释原料、工序辅料、包材、人工、设备、其他和副产回收；单盒成本按真实入库盒数计算。
- 物料价格缺失显示“—”或待补价格，不能伪装为 0 元。

## 16. 销售交付与财务闭环

1. 销售从已入主仓/外仓的成品创建发货任务，填写计划日期、地址与数量；创建任务时不立即扣库存。
2. 仓管分配实际来源仓与 FEFO 批次，批次分配合计必须等于实发量；仓库确认后才扣库存并生成送货记录。
3. 支持部分发货；累计实发不能超过订单量，重复确认不能重复扣库。
4. 销售发起开票申请，财务审核；登记收款后核对应收余额。
5. 销售退货草稿不直接改变库存或资金；审批后再处理退货入库、退款和应收变化。

## 17. 盘点闭环

菜单路径：仓储管理 → 盘点管理。

1. 盘点前记录原料、半成品、成品按仓库与批次的系统数量和单位。
2. 发起盘点任务，选择仓库、月份或页面允许的专项盘点方式。
3. 录入实盘数量并保存暂存；暂存时库存不变。
4. 提交审批并由有权限人员审核；审批完成后库存仍未调整。
5. 点击应用差异后库存才等于实盘数量；同一差异只能应用一次。

## 18. 撤回、冲销与审计

- 草稿或待审报工可取消；正式落账必须走撤回或冲销单据，禁止删记录或直接改库存。
- 冲销审批后，原料补回、半成品/成品产出失效，成本重算；原报工与冲销单互相可追溯。
- 半成品已被下游消耗或成品已调拨/发货时，系统应指出具体下游占用并阻止上游冲销。
- 旧生产计划保留创建时的 BOM 与 Workflow 快照；新版本只影响之后创建的计划。

## 19. 回答常见问题的口径

### 为什么 Workflow 不填写 1kg 产 1盒

Workflow 的单位关系只声明投入用 kg 报工、产出用盒报工，不预设实际出成率。`1盒=800克` 已由成品 SKU 定义，真实投入、产出与出成率在报工和成本分析中形成。

### 多个原料是否必须全部投入

不是。多个原料 Cell 连接到同一工序时，当前口径是批次自由选择且至少 1 个；用户可以选择一个、多个或全部，不再区分主投入和追加投入。

### 副产物要不要单独建 Workflow

不需要。副产物在具体报工中记录；只有真实存在独立后续工艺或库存主数据需求时，才另行评估建档。

### 为什么选择成品时弹出多个 Workflow

因为多个已启用 Workflow 在完全匹配或同级最小超集层级上重叠。用户必须通过工序链预览选择正确路线；系统不能靠 Workflow 名称自动猜测。

### 报工完成为什么成品还没进主仓

报工、生产结单、仓库确认完工入库、生产仓到主仓/外仓调拨是四个不同动作。只有仓库确认后生产仓库存生效，再完成仓间调拨后主仓/外仓才增加。
