# 覆盖矩阵

> **动态更新**: 此矩阵随功能增加自动扩展。每次运行 E2E 测试时，
> 应先扫描 web-admin 的路由文件 (`web-admin/src/router/`) 获取最新模块列表，
> 与此矩阵对比，发现新增模块自动提示需要补测试。

## 自动发现新模块

每次测试运行前，执行以下检查：
1. 扫描 `web-admin/src/router/index.ts` 获取所有路由
2. 扫描侧边栏配置获取所有菜单项
3. 对比已有测试覆盖列表
4. 新增模块标记为 ⬜ (未覆盖)，提醒补充测试

## 新增模块处理规则

当检测到新模块时：
1. 自动创建 Layer 1 测试（页面可访问性）
2. 提示需要补充 Layer 2 CRUD 测试
3. 如果新模块与已有模块有数据关联，提示补充 Layer 3 跨模块测试
4. 更新此矩阵
