0.3 — 原料字典 (含单位 + 二级换算)

f006_warehouse_mgr 或 f006_admin

菜单: 仓储管理 → 原料类型字典 (新建原料) · URL: /warehouse/material-types

操作
  1. 点 + 新增
  2. 填:
    • 原料名称 (必填): 如 冻猪蹄
    • 类别 (必填 dropdown): 原料 RAW / 辅料 AUXILIARY / 包材 PACKAGING

0.4 — BOM 配方 (核心: 成品克数 + 出成率)

f006_admin / f006_production_mgr

菜单: 生产管理 → BOM 成本管理 · URL: /production/bom

客户算法: 原料投量/份 = 成品含量 ÷ (出成率/100)
例: 一份成品里有 200g 猪蹄, 卤制出成率 58% → 需要原料 200 / 0.58 = 345g 冻猪蹄/份
操作
  1. 顶部 选择产品 dropdown → 选 叮咚好食光卤猪蹄(去大骨) 200g
  2. 点 + 新增配方项
  3. 切 原料 tab (RAW) → 填:
    • 关联原料 (必选 dropdown): 选 冻猪蹄 → 自动回填名称 + 单位 (B8 fix per PR #293)
    • 成品含量 (必填): 200 (g, 一份成品中此原料克数)
    • 出成率% (必填): 58
    • 单价(含税) (可选, 仅 procurement_mgr/admin 看到): 留空或填进价
    • 税率% (可选): 13
  4. 保存 → 列表显示该行, 原料投量/份自动算 = 200/0.58 = 345.0g
  5. 切 辅料 tab → 加食盐 + 卤料包 (成品含量 2g, 出成率 100%)
  6. 切 包材 tab → 加 200g 塑盒 + 装箱纸盒 (成品含量 1, 出成率 100%)
  7. (可选) 切 工序 tab → 加报工单价
比如说我这个是 200 克, 那我可能就写个 200, 这个最好加个单位, 尽量单位是克.
200 克我的出成的话是 58% 嘛, 那么自动机啊.— May 10 L230-232

  • 📝 普通新建: 完整表单 — 一次创建一个, 所有字段可填 (供应商/规格/付款方式/备注等). 适合: 单条订单, 字段都要填全

  • 📊 BOM 展开: 基于 BOM/配方 — 选模板自动展开明细 (e.g. 产 100 个成品 → 自动算出需要的原料 PO). 适合: 跟生产任务联动
