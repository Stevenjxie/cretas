# qhj 数据与分析 + 餐饮运营 UX 评审 (2026-06-02)

Steve 对 qhj_prod (RES_3101_009) 全量分析侧逐页评审, 滚动捕获。核心矛盾: **几乎每个页面都要用户"选择数据源(上传的 CSV)"或选窄日期范围(默认近 30 天→无数据), 而 qhj 全量数据已在 gold 层**。要的是: 自动从 gold 聚合 + 合理默认时间(全部/一年) + 默认就出分析 + 精简散页。

## 统一原则 (贯穿所有页)
1. **杀掉"选择数据源(CSV)"选择器** → 自动从 gold 层聚合 (POS 全量 + 19845 条点评都在 gold)。
2. **默认时间 = 全部 / 近一年** (不是近 7/30 天 → 现在常"无数据")。
3. **默认就生成分析 + 洞察** (不是让用户"另外点生成")。
4. **散页合并** → 同类分析归到一个模块, 删冗余页。
5. **平台口碑用我们已有的点评数据** (不是要求另外上传)。
