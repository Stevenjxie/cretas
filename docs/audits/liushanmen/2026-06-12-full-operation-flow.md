## G·研发报价

> 流程入口: 销售与客户沟通形成出户意向 → 下达研发任务  
> 出处: catalog G·研发/产品经理报价 30条; transcript.txt (前场张权39min)

### G1. 接受研发任务
- **谁**: 研发(产品经理)
- **操作**: 接到销售下达的"出户意向"任务，确认工艺方向、口味要求、客户价位区间
- **系统**: 记录研发任务(系统关联点，P1阶段完善)
- **出处**: [00:27]-[00:57] 行2-3 "研发自己研发、自己包价、自己生产、自己卖"
- **注**: 研发试样选料 = 价位区间驱动，看仓库有什么用什么，不是BOM定死原料

### G2. 建产品档案(SKU)
- **谁**: 研发(产品经理)
- **操作**: 在系统中新建产品 → 填品名/规格/单位 → 配置工序模板(搭积木)
- **系统**: 系统自动识别规格，生成产品编号流水号；AI可辅助自动匹配工序(existing)
- **出处**: 行45-48 [08:45]-[09:01] "研发产品通过后开始建品(建SKU)"; [56:04]-[56:23] 行1727-1736 "产品-工序匹配，AI可自动帮忙添加工序"
- **决策注**: SKU只存成本价，不存建议销售价 (决策2-B)；编号自动生成非手填 [99:29]-[99:34]

### G3. 建BOM配方
- **谁**: 研发(产品经理)/技术组
- **操作**: 在SKU下建BOM → 填各原料/辅料/包材的用量比例 → 填预估出成率 → 人工成本研发自己凭经验评估手工填入
- **系统**: BOM价格来源=采购实际进价(由采购后续填入，非研发填定); BOM中含原料/辅料/包材比例，人工在预报价层独立
- **出处**: 行49-52 "建品时建产品BOM"; [14:51]-[15:01] 行295-299 "预报价里有人工，BOM是BOM的(BOM=用量配方不含人工)"; 行1251-1264 "BOM不直接填价格，价格跟采购进价走"
- **决策注**: BOM只管用量配方；人工在预报价层，两者独立，不可混淆

### G4. 出预报价
- **谁**: 研发(产品经理)
- **操作**: 根据BOM原料估价 + 研发凭经验评估人工(折算每件占多少人工×人工单价) → 生成预报价/预收价
- **系统**: 系统结合填入的人工成本生成预报价
- **出处**: [02:27] 行8 "研发会先出一个预报价"; [15:13]-[15:33] 行313-331 "评估大概用多少人，折算后每件占多少人工，乘人工单价算成人工费用"; [18:22]-[18:23] 行492-493 "填进人工成本后产生预收价"

### G5. 安排中试批量
- **谁**: 研发(产品经理)
- **操作**: 根据预报价安排中试，生产小批量(100~200公斤)
- **系统**: 中试批次进入研发库(独立研发库，不混入可售库存)
- **出处**: [02:27] 行8 "出预报价后进行中试，先做100、200公斤小批量"; 附录1 [06:22]-[06:34] "是试的嘛，隔天单独的一个库能管理，研发专门的"

### G6. 核算中报价并比对预报价
- **谁**: 研发(产品经理)
- **操作**: 依据中试实际数据出中报价 → 与预报价对比 → 差异不大按原样，差异大(毛利变负)则涨价或放弃
- **系统**: 系统展示预报价 vs 中报价对比
- **出处**: [02:27]-[02:56] 行8-9 "据中试实际生产数据出中报价与预报价比较；差不多按预报价做，差很多就不做或重新定价"
- **异常流**: 差异大→告知客户涨价→客户不接受→放弃该品 ([03:50]-[04:20] 行11)

### G7. 研发向系统维护价格(成本价)
- **谁**: 研发(产品经理) + 财务最终上盘
- **操作**: 研发核算完成后，财务最终提交价格上盘，系统对应价格作为系统成本价；销售后续建单时引用
- **系统**: 成本价写入产品档案，作为销售毛利红线计算基准
- **出处**: 行14 [05:22] "那是一个产品库，他维护好产品库，价格他自己往里面一填"; 行16 "报价最终由财务提交/上盘，作为系统成本"

### G8. 系统自动触发后续建报价任务
- **谁**: 系统(自动)
- **操作**: 报价审核通过后，系统自动建报价任务、BOM草稿、通知销售
- **系统**: ⚠️spec派生无转录依据 — 该自动化触发逻辑未在转录中明确说明
- **出处**: 无直接转录依据；基于G流"研发自己卖"的闭环推断

## E·销售

> 流程入口: 中台(销售)接到客户订单 → 创建销售订单  
> 出处: catalog E·销售到开票 26条; transcript.txt + transcript-2b.txt

### E1. 中台消化客户订单
- **谁**: 中台/销售
- **操作**: 与客户沟通，确认产品、数量、交货期、计价方式(加工费+原料费分拆 或 包工包料一口价)
- **系统**: —
- **出处**: 行12-13 [04:51]-[05:22] "两种计价方式：加工费+原料费拆分 vs 一次性包工包料成品价"; 行13-14 [05:22]-[05:46] "给客户最终报价不拆分明细，只给一个最终价"

### E2. 创建销售订单
- **谁**: 中台/销售
- **操作**: 系统中创建销售订单 → 选客户/日期/交货地址/业务员/预定合同 → 加产品(规格自动绑定) → 填单价(此时可空，参考研发理论包价) → 填数量(按公斤计)
- **系统**: 规格自动绑定；单价含税/不含税两字段；低于毛利红线时单价显示红色预警(非阻断)
- **出处**: 行1774-1780 [57:58]-[58:16] "创建销售订单：选客户、日期、交货地址、业务员、预定合同"; 行1792 [58:55]-[58:59] "订单单价/成本后面才有，下单时可空"; 行100-104 [10:44]-[10:51] "创建销售订单时单价可填，低于底价提示红色/预警"
- **决策注**: 毛利红线按毛利率反算最低售价(决策2-B)；算例：成本8块毛利率10%则最低售价不低于8×(1+10%) 行104-122 [10:51]-[11:23]

### E3. 提交财务审核
- **谁**: 中台/销售
- **操作**: 订单填好后提交财务审核
- **系统**: 财务审核界面展示：订单成本/明细/下单时间/数量/单价/小计；财务可看价格趋势比价
- **出处**: 行1793-1803 "财务审核时展示订单成本/明细/下单时间/数量/单价/小计"; [17:21]-[18:00] 行450-481 "销售计划→下单→财务审批→流转车间→排产闭环"

### E4. 财务审核通过
- **谁**: 财务
- **操作**: 财务审核订单成本明细 → 通过
- **系统**: 审核通过后回到销售订单，状态置"已通过"；系统自动生成含税/未税凭证三行(科目对应)
- **出处**: 行1853-1860 "审核通过后回到销售订单，状态置已通过"; 行1820-1823 [59:52]-[59:57] "销售单价需同时显示含税与不含税两个值"
- **注**: 自动含税凭证三行 → ⚠️spec派生，转录中描述的是凭证表格格式，三行具体科目需客户确认

### E5. 销售收尾(发货后)
- **谁**: 中台/销售
- **操作**: 货已发出 → 在系统触发收款确认 → 通知财务"钱已收"
- **系统**: 财务确认已收款 → 开票 → 发票自动传给销售 → 销售下载发给客户，流程结束
- **出处**: 行1137-1154 [41:13]-[41:34] "财务看到'钱已收'→开票→发票自动传给销售→销售下载发给客户即结束"
- **注**: 票务管理：采购入票、销售开票是否到位需跟踪；客户自管开票动作 行993-997 [37:31]-[37:44]

### E6. 盐化销售独立处理
- **谁**: 做盐化业务的销售
- **操作**: 盐化业务不走普通销售供单 → 销售自己建盐化供单("谁盐化谁建")
- **系统**: 盐化供单独立扣减，最终统计/报表归盐化口径，不混入正常销售报表
- **出处**: [91:43]-[92:03] "盐化通过单独建一个销售单位/盐化供单实现，不走销售供单"; [91:46]-[91:54] "谁盐化谁建"

## D·采购

> 流程入口: 销售订单确认后生成净需求 → 采购建PO  
> 出处: catalog D·采购到付款 49条; transcript-2b.txt

### D1. 确定采购需求(两种模式)
- **谁**: 采购员
- **操作**: 
  - **模式A(跟销售订单)**: 在采购界面看到销售订单 → 点"开始采购" → 弹窗带入相关明细(原料/辅料/包材) → 不用手写不用选，系统关联
  - **模式B(自主采购)**: 采购自己判断需求(野区型/一次性) → 自己填品类和价格
- **系统**: 系统按BOM反推预领量，驱动采购需求；库存不足时采购和仓库同步收警报
- **出处**: 行1867-1879 "做个弹窗，选订单后直接带入相关明细"; 行1219-1241 "两种采购模式：自主采购 vs 跟销售订单采购"; 行3017-3025 "反推领料量驱动采购+仓库，库存不足同步报警"

### D2. 创建采购订单(PO)
- **谁**: 采购员
- **操作**: 填写PO → 供应商 → 原料名称(下拉选，与BOM一致) → 数量(意向值) → 单价(含税/未税两字段+税率) → 付款属性(现结/赊结/月结/账期) → 发票状态(预付/未到票) → 可填合同号
- **系统**: 采购合同号挂在采购模块下；历史批次价格永久留存
- **出处**: 行1995-1998 "采购单价要设置未税和含税，加上税率"; 行806-838 "采购下单时多选付款/票据属性"; 行1 "合同归属采购、有合同号"; 行1207-1218 "价格跟着采购订单走，每个品填金额即可"
- **注**: 多个关联订单可按供应商/品类合并成单一采购单 [100:50]-[101:00]

### D3. 提交财务审批
- **谁**: 采购员
- **操作**: 在采购界面下方直接提交审核(不切界面)
- **系统**: 审核流转到财务；财务审核内容同销售端(有价格趋势)
- **出处**: 行1972-1985 "上架成功后做财务审批，提交审核在采购界面下方直接做"; 行1990-1994 "采购审批后财务也能看到"

### D4. 财务审批通过
- **谁**: 财务
- **操作**: 审核采购单价格/数量合理性 → 通过
- **系统**: 采购单状态更新；数据传到供应商付款链路
- **出处**: 行1853-1866 "通过后回到销售集团/平台，采购就出去了"

### D5. 单据下发给供应商
- **谁**: 采购员
- **操作**: 打印采购单(纸质/PDF/照片) → 发给供应商
- **系统**: 系统生成单据供打印；供应商送货能带单就带，带不了工厂自己发送货凭证兜底
- **出处**: 行2033-2049 "打印自己打，要不发PDF/照片也行"; 行2044-2050 "能带就带，带不了就自己发信息"

### D6. 供应商到货 → 仓库收货
- **谁**: 仓管员
- **操作**: 凭采购订单号匹配(扫码或网页选单) → 核对实物数量/品类 → 填入实际入库数量(与订单数量分两字段)
- **系统**: 实际入库值为准，与采购数量(意向值)分开记录；超收/少收均允许
- **出处**: 行2124-2156 "入库匹配采购订单号才能入库"; 行2276-2302 "采购入库表新增'实际入库值'字段，采购数量=意向值，实际入库值=准"
- **异常流-超收**: 到货比PO多(如订100到120) → 先入库 → 单子结束后系统生成异常动单退回采购账号 → 采购决定退还是入 → 要退则建采购退货单 行2308-2389
- **异常流-少收**: 到95箱则入库改为95 → 反馈采购 行2162-2176

### D7. 入库确认 → 提交财务审批
- **谁**: 仓管员
- **操作**: 核对完毕 → 确认入库 → 提交财务审批
- **系统**: 财务审批通过后库存正式增加；采购入库数据传到财务模块生成对应供应商财务数据
- **出处**: 行2119-2124 "入库需确认，且要提交财务审批"; 行638-644 "入库后对供应商的数据，财务通过入库单生成财务模块数据"

### D8. 发票管理
- **谁**: 采购员
- **操作**: 票已到 → 上传发票到系统
- **系统**: 系统自动显示"票已到"并自动核销；未到票则按配置提醒周期定时催票
- **出处**: 行1092-1110 "未到票设定提醒周期(到期催票)；票到后采购上传发票，系统自动显示票已到并自动核销"

### D9. 提付款申请 → 审批 → 出纳付款
- **谁**: 采购员(发起) → 财务/老板(审批) → 出纳(执行)
- **操作**: 订单全入库后 → 采购提付款申请 → 流转双端审批(电脑+手机) → 全节点审完
- **系统**: 审批完成后数据传出纳；出纳看到：产品名称/采购订单/供应商/原料名称/单价/数量/计量 → 出纳执行付款
- **出处**: 行1015-1085 "完整付款链路+出纳只读终端角色"; 行1057-1079 "出纳能看到产品名称、对应采购订单、供应商、原料名称、单价、数量、计量，拿这个就付款"
- **注**: 出纳是独立只读角色；付款也可腾数据到钉钉给老板批后穿回

### D10. 采购退货处理
- **谁**: 采购员(发起) → 财务(审批) → 仓管(执行)
- **操作**: 确认需退货 → 在采购订单里建退货单(整批) → 提财务审批 → 审批通过给仓管出货
- **系统**: 退货单流转财务审批；审批通过通知仓管把实物拿走(出货管理)
- **出处**: 行2337-2416 "退货由采购发起，整批；在采购订单里退；退货单发财务审批，审批后给仓管把实物拿走"; 矛盾后明确 "退货跟钱有关，必须先财务审批确认"

## C·生产(核心)

> 这是客户描述最详细的流程，是系统核心  
> 流程入口: 销售订单审核通过 → 厂长排产  
> 出处: catalog C·生产闭环 78条; transcript.txt (前场张权39min最集中)

### C1. 厂长排产
- **谁**: 厂长/PMC(生管)
- **操作**: 查看已审核的销售订单 → 安排生产日期(哪天做) → 创建生产计划
- **系统**: 生产计划可关联销售计划，下面产品类型等自动关联只要确认；计划推迟不影响系统，以实际开工日为准
- **出处**: [17:21]-[18:00] 行450-481 "财务审批完流到张权，按订单排产(排哪天做)"; [104:13]-[104:23] "选一个销售计划，下面产品类型等可自动关联"; [86:08]-[86:24] 行2864-2877 "排4号没做推5号推6号都不影响，以实际开工日为准"

### C2. 多SO合并为一张生产工单
- **谁**: 厂长/PMC
- **操作**: 同一品有多个销售订单 → 在建生产单时加号追加多个销售单号 → 合并为一张供单
- **系统**: 系统支持动态追加销售单号；一个供单可关联多个SO；销售单号和生产单号双向互查
- **出处**: [100:50]-[103:30] 行3650-3730 "建销售单时下面有加号可逐个追加销售单号，合并结果仍是单一供单"; [103:13]-[103:53] "系统须支持销售单号和生产单号双向检索"

### C3. 生成领料配料单(汇总单)
- **谁**: 系统(自动) → PMC确认
- **操作**: 系统按BOM自动反推预领量 → 生成领料汇总单(全物料合并总需求)

## B·成本

> 流程说明: 贯穿生产全流程，不是独立时序流，而是随各环节数据填入后系统自动核算

### B1. 三价并行维护
- **谁**: 研发/采购/财务

- **谁**: 系统(自动)
- **操作**: 生产领用原料/辅料/包材 → 系统按BOM对应产成品数量分配成本
- **系统**: 每批次投不同料，各批次成本不一样；原料入库后价格锁定不动；成本核算用未税价

- **操作**: 今天淋1吨用500kg剩500kg → 下批投这500kg同时又淋1吨(一吨一价格) → 系统加权计算混合价格
- **系统**: 半成品+原料同步投入时按移动均价加权计算；SemiFinishedInventory/WIP移动均价/sourceWipNo复用

### B5. 成本拆分(料+人工+制费)
- **谁**: 系统(自动) + 财务确认
- **操作**: 系统拆分每盒成本：BOM原料辅料包材部分 + 人工部分(工时×人数×工价)

### B6. 超支预警(百分比阈值)
- **谁**: 系统(自动通知)
- **操作**: 实际成本 vs 标准BOM成本 → 偏差 > X%(可配，默认~10%) → 触发超支预警
- **系统**: 超支报警用百分比阈值；销售毛利红线用毛利率

### B7. 人效双口径对比
