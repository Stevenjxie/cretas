**日期** 2026-08-18 · **租户** MOCK_REST · **环境** prod 活代码（部署后真跑，2 轮一致）
**起因** PR #2872 让「目录里查不到的提及」被丢掉，我要量**自己引入的风险**

---

## 〇 · 我要量的风险

`_mentions_backed_by_catalogue` 把查不到的提及丢掉。那么：

```
(a) 老板问一家**真实存在但还没进 dim_store 的新店**
    → 原来会说「没有找到名为 X 的门店」（诚实）
    → 现在被丢掉 ⇒ 会不会**静默按全店回答**？（那就是编答案）

(b) 「量子纠缠火箭发射器」那条阴性对照还在吗？
```

▎**修一个「不该拦的被拦了」，最容易顺手造出「该说的不说了」。**
▎形态 C⁶：修复的进度会掩盖修复的缺口。

## 二 · 🔴 缺陷一（新发现）：不存在的店名被匹配到 4 家**毫不相关**的店

```
「模拟·青浦新开店最近30天营收多少」

→ 你说的「模拟·青浦新开店」，我这边有 4 家对得上：
   模拟·浦东金桥社区店、模拟·杨浦五角场店、模拟·徐汇美罗城店、模拟·闵行莘庄社区店。
   你要看哪一家？

spec: store_slot='模拟·青浦新开店'  store_scope=None  dims=('store',)
      kind=clarification  n=75
```

**那 4 家里没有一家跟「青浦」有关。** 共同点只是都带「模拟·」前缀和「店」字。

▎「我这边有 4 家**对得上**」是一句**站不住的话** —— 老板去看那 4 家，一无所获。
▎而它长得像「我在帮你消歧」，所以他不会怀疑，只会觉得这东西不太懂他。

### 它和「需要复盘的门店」不完全同形

| | 「需要复盘的门店」（PR #2859 已修） | 本条 |
|---|---|---|
| 病 | 有依据，但**没阈值** —— 平数据上误发 | **依据本身是假的** —— 匹配度低到无意义，却报成「对得上」 |

### 归属与边界

来自 `_resolve_store_mentions` 的 `is_ambiguous` 分支
（`restaurant_intent.py` 约 5232 行 → `entity_resolution.shortlist.resolve_mention`）。

⛔ **本轮不改** —— `restaurant_intent.py` 另有一条线在改（#1 菜单核对 / #13 菜品归一）。
线索已发给「误发提示普查」那条线（它的靶子正是这一类），附了 prod 原文。

### 🔴 值得单独量的一个数（登记）

**在脏样本上会严重得多**：`R_GML_DEMO` 有 **132 家**「桂满陇（XX店）」——
那种高度同名的目录下，随便一个错名字可能匹配到几十家。

⚠️ 这正是「MOCK_REST 只做冒烟、不做验收」那条纪律：
**10 家的目录量不出这个量级。**

## 三 · 🔴 缺陷二（交叉验证）：菜品侧核对没接

```
「量子纠缠火箭发射器最近30天营收多少」

→ 你问的是**某道菜**，我这次挑到的却是全店合计，所以这次我没敢算。

spec: store_slot=None   ← ✅ **门店侧我的核对起作用了**
```

📏 之前实测这句是「`store=None` + 我不会编造答案」，现在变成「你问的是某道菜」
⇒ 产品把「量子纠缠火箭发射器」**当成了菜名**。

⇒ 这**独立复现**了 owner 派出去的 **#1 菜单核对没接上**
（`_catalogue_says_not_a_dish` 在 `restaurant_intent.py` / `restaurant_intent_service.py`
的调用点都是 **0**）。已有一条线在修，本轮**只登记不动手**。

▎门店侧对了、菜品侧还没接 —— **两侧是同一个判据的两半**，
▎而只修一半的表现就是「拒答理由从『某家门店』变成『某道菜』」。

## 四 · 这份回归留下来的资产

`smartbi/scripts/_catalogue_regression.py` —— 5 条用例，每条写明**期望看到什么**：

```
阳性·真店全名     该答上，且点名这家店
阳性·真店简称     该答上（简称归一）
🔴风险a·没进目录  该说查不到这家店，⛔ 不该静默按全店回答
🔴风险b·完全不存在 该说我不会编造答案
对照·本轮修的那句  不该再出现假拒答
```

⚠️ 阳性对照（真店问句 `kind == "answer"`）**进 rc 判定** ——
一条都没答上就 `rc=2`，让「产品坏了」和「我没跑起来」分得开。

⛔ **它不进 CI** —— 需要真 LLM + prod 库。它是**部署后手跑**的那一类。
