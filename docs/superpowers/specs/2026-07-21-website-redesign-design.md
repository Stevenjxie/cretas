## 1. 改版目标

1. 官网停在 2026 年 2 月，产品已跑到 7 月 — 补上半年的能力演进
2. 业务线从「工厂 + 餐饮」扩为 **工厂 / 餐饮 / 物流 / AI 中枢 / 定制开发** 五条
3. 每条业务线内容加深：讲功能与差异化、突出 AI 赋能，**不堆技术细节**（展示型站点，面向食品工厂/餐饮/物流客户老板）
4. 视觉全面改版（旧深色科技风 → 「AI 之眼」摄影标注风）

## 3. 视觉系统 — V6「AI 之眼」融合版

概念稿存档: `.superpowers/brainstorm/1248-1784612471/content/visual-style-v4/v5/v6.html`（V6 定稿）

**签名式设计语言**: 真实摄影 + AI 识别标注层 — 官网自身演示「AI 看得懂你的车间」。

| 要素 | 规范 |
|---|---|
| 底色 | 暖灰白渐变 `#fdfcfa → #faf8f4`，照片暖光 ambient glow 溢出到背景 |
| 主色 | 墨黑 `#111`（文字/按钮）；**AI 工作色** 绿 `#00b377`（CTA）/ `#00e28a`（识别标注） |
| 图片衔接 | hero 底边 `mask-image` 渐变溶解进页面（无硬边）；照片卡用照片同色系光晕投影（无边框）；LIVE 字幕条为骑在照片/页面交界的白玻璃胶囊（backdrop-blur） |
| 圆角 | hero 容器 18-22px 内嵌；照片卡 14-16px；标注标签/按钮胶囊形；识别框 8-10px |
| 排版 | 中文黑体重字重大标题（PingFang/思源黑体 900）；批次号/标注用等宽字体；识别标签 7-8px 胶囊 |
| AI 标注层 | 识别框（绿描边+圆角）、置信度标签（"操作员 · 装盘工序 98.2%"）、LIVE 实时字幕条 — 内容必须来自真实产品能力 |
| 图标 | ⛔ 禁 emoji，一律 inline SVG（Lucide 风格单色描边） |
| 禁用模板语法 | ⛔ 大数字指标行 hero-metric、同款卡片阵、每节小眉题（uppercase tracked eyebrow）、渐变文字、玻璃拟态滥用 |
| 动效 | 滚动时光晕视差微移、识别框渐入、LIVE 条滚动播报；全部尊重 `prefers-reduced-motion` |
| 摄影素材 | Unsplash（已验证 200）: 暖光后厨 `photo-1577219491135-ce391730fb2c`(hero)、仓储货架 `photo-1587293852726-70cdb56c2866`、卤肉面 `photo-1526318896980-cf78c088247c`、公路货车 `photo-1519003722824-194d4455a60c`；正式实现下载到 `platform/assets/` 本地化（不依赖外链），后续可换自有实拍 |

## 4. 业务页统一模板（场景痛点驱动）

每页 5 段式：
1. **Hero** — 行业摄影 + AI 标注层 + 一句差异化承诺
2. **3~6 个场景模块**（主体）：痛点场景开场 → Cretas 怎么解 → AI 在里面干了什么（绿色标注视觉）→ 真实截图佐证
3. **差异化对比条** — vs 传统 ERP / vs 人工（只讲结果）
4. **客户之声** — 脱敏原话
5. **CTA** — 预约演示

产品素材：web-admin / RN App 真实截图（数据脱敏）套设备壳，与摄影混排。

## 5. 各页内容清单（均有代码证据，盘点于 2026-07-21）

### 5.1 首页
- Hero「你的生意，AI 亲眼盯着。」+ 识别标注 + LIVE 字幕条
- 四业务照片条（不等宽）+ AI 中枢对话卡
- 定制开发一节（一句主张 + 入口）
- 客户原话收尾（"你告诉他要收多少，就行了。"）

### 5.2 食品工厂（7 场景，视觉 AI 为重头戏）
1. 收货防呆 — "告诉他要收多少就行"（MaterialReceiptAI + 电子秤视觉接入）
2. 生产报工与工序流转 — 可视化工作流编辑器、多工序良率报工、NFC 打卡
3. **⭐ 车间视觉 AI**（独立大段）：人效识别（工人数/干活空闲/动作计件/11 类工序自动识别/效率评分）、安全合规（工作服帽子手套穿戴检测）、异物检测、海康/大华摄像头即插即用
4. 批次全链溯源 — 30 秒追到人 + 消费者扫码公开溯源
5. BOM 配方与成本 — 版本/ECN 审批、一句话转 BOM、FIFO 推荐、过期/低库存预警
6. 质检 HACCP — CCP 监控、拍照+语音质检、处置闭环
7. 下单到开票一条线 — 销售→排产→出库批次分配→开票，设备冷链监控

### 5.3 餐饮连锁（6 场景，2026-07-11 竞品交流录音提炼）
1. 老板每天早上的 5 条信息 — AI 主动说今天干什么（RestaurantOwnerActionAdvisorTool）
2. 营收跌了，AI 追到根 — 归因树（追到"每周一中午"+商圈外部对比）
3. 供应商的账，暗箱翻不了 — 价格异常即时到老板、对账
4. 单品毛利算得清 — 菜品成本/损耗/滞销，大白话问答+语音叫料
5. 烂表格也能用 — 任意 Excel/收银导出，AI 认表头洗数据（收银厂商表头不一痛点）
6. 你的数据在你手里 — 本地部署盒子、数据不喂平台
- ⛔ 线上平台运营（点评/投流）**不上官网**（非现有能力，且属交流对象方向）

### 5.4 物流配送（5 场景）
1. 十辆车一个人调 — 智能调度、派车派司机、按天运力
2. 装载率优化 — 6 趟变 5 趟、运力诊断
3. 地图路线与执行跟踪 — 多地图路由、冷链温层、配送执行状态
4. 任意 Excel 一键导入 — 表头智能匹配、地址智能纠错
5. 异常与准点

### 5.5 AI 中枢（定位：会干活的 AI 员工，5 段）
1. 600+ 项业务能力（口径：实测 603 个工具实现类，官网写 600+），覆盖 50+ 业务领域
2. 看得懂（视觉）/ 听得懂（语音）/ 算得清（SmartBI 编排）
3. 动手有分寸 — 写操作先预览确认、按角色限权（"放心让 AI 动手"）
4. 主动吭声 — 过期/缺料/价格异常/目标预警
5. 越用越懂你 — 只写效果不写机制（⛔ 不提蒸馏/强化学习等实现）

### 5.6 定制开发（轻页）
- 主张：**"让产品适应工厂，而不是工厂适应产品。"**（2026-07-11 录音中自方原话）
- 叙事：传统定制开发数百万起 → Cretas 细颗粒模块 + AI 编排，低价快速交付
- 案例胶囊（全脱敏，只讲能力）：进销存一体（PSI）、AI 用量配额治理、商城+小程序（含 AI 店铺装修）、低代码页面/表单编辑器、AI 生成打印模板

## 6. 脱敏规则（HARD）

1. 不出现任何真实客户名/品牌名/人名/公司名（含录音中的所有第三方）
2. 截图数据一律脱敏（工厂名/金额/联系人替换为演示数据）
3. 客户原话可用但匿名（"某食品工厂负责人"）
4. 测试账号/凭证/内部端口不出现

## 7. 实施约束

### 7.0 设计 skill 路由（HARD — Steve 2026-07-21 要求）

文案与排版设计**必须通过设计 skill 完成**，不徒手写：

| 环节 | 必用 skill | 用途 |
|---|---|---|
| 每页排版/布局开工前 | `design`（创意展示页路由）+ `impeccable`（craft/shape） | 页面结构、版式、register 校准 |
| 设计 token / 组件规范 | `ui-ux-pro-max`（--design-system 落 MASTER.md）| v6.css tokens 统一 |
| 文案 | `impeccable` clarify + 本 spec §5 场景话术 + 录音提炼原话 | 全人话、无技术腔、无模板语法 |
| 动效 | `apple-design`（材质/衔接）+ `gsap-frameworks` | 光晕视差、识别框渐入、reduced-motion |
| 每页完成后 | `impeccable` audit/polish | 对比度/响应式/AI slop test 把关 |

- 纯静态 HTML/CSS/JS，延续 platform/ 现有形态；共享设计 tokens 抽 `css/v6.css`
- 响应式 375/768/1024/1440；照片 WebP + lazy；`prefers-reduced-motion` 全覆盖
- 部署仅到 139（`server-operations` skill 规范）；工作在独立 worktree，commit 用 scoped `git commit -- <files>`
- 旧页面不删，跳转归档
