# SKU、BOM、Workflow 与生产报工统一单位设计规格

**状态**：已确认，可实施

**确认日期**：2026-07-15

**目标**：建立单一单位真值，消除 SKU、BOM、Workflow、生产库、报工、仓储和销售之间的 g/kg/盒/袋/箱漂移，同时保留历史快照与可逆库存治理。

## 1. 设计原则

1. SKU 管单位，BOM 管配料与工序归属，Workflow 管流程拓扑，报工只记录实际业务数量。
2. 原料和半成品的库存与报工质量单位统一为 kg；g 仅作为配方表达或临时查看单位。
3. 固定包装成品按盒、袋、件等基本单位记账；散装称重成品才按 kg 记账。
4. 规格字符串、包装总重、工序单位提示均由结构化字段生成，不作为计算来源。
5. 生产计划保存 SKU、BOM、Workflow 版本及单位快照；历史单据不随主数据变化重算。
6. 正式库存变化必须由仓储流水、生产小结、撤销小结、退料或盘点产生，禁止直接改余额。
7. 所有质量计算使用十进制，不使用浮点数。

## UX Flow Analysis

### 用户与任务

- 产品管理员维护 SKU 基本单位、标准净重和包装规格。
- BOM/工艺管理员维护配料、配料出成率及配料所属工序。
- 仓管维护原料仓与生产库之间的批次转移、退料、成品包装组合和盘点。
- 报工人员只填写实际投料、实际产出、留样、开始时间、结束时间和人数。

### 防呆边界

- 单位均由上下文继承并只读显示，报工人员不能改单位。
- 生产库不足时在提交前显示需要量、可用量和缺口，只允许保存草稿。
- 入库、剩余、重量、出成率、时长和人工工时均自动计算。
- 多包装规格不进入 Workflow 或生产报工。
- 已产生业务数据的 SKU 基本单位不可直接修改。
- 未配置理论出成信息时显示“未配置/数据不完整”，不伪装为 0。
- 错误信息必须包含对象、当前值、限制值和下一动作。

## 2. SKU 领域模型

### 2.1 SKU 类型

统一 SKU 管理包含：

- 普通成品 SKU
- 客户自带原料加工 SKU
- 纯代工 SKU
- 半成品 SKU

原料仍由原料字典管理，不进入 SKU 管理。

### 2.2 半成品 SKU

半成品 SKU 仅维护编码、名称、类型、状态和固定基本单位 kg。它不维护标准净重、装箱规格或预计投入产出比。

Workflow 可以选择已有半成品 SKU，也可以快速创建。快速创建必须生成正式 SKU 记录并立即出现在 SKU 管理中。已被 Workflow、库存或报工引用后只能停用，不能硬删除或修改基本单位。

### 2.3 固定包装成品

固定包装成品基本单位为盒、袋、件等计数单位。标准单位换算定义为：

`1 基本单位 = 标准净重`

例如 `1袋 = 200g`。标准净重达到 1000g 后可统一按 kg 展示，但基本单位仍为袋。

### 2.4 散装成品

只有按重量生产、入库和销售且没有固定单包数量的成品才允许使用 kg 作为基本单位。质量型 SKU 不填写标准净重。

### 2.5 单位变更治理

- 无业务数据的 SKU 可以修改基本单位和标准净重，并同步未开始计划及 Workflow 草稿。
- 已有库存、报工、入库或销售记录的 SKU 禁止直接修改基本单位。
- 实际规格不同必须新建 SKU；录错单位必须走受控迁移。
- 标准净重和包装规格的新版本只影响未开始计划；已开始与已完成批次使用快照。

## 3. 包装规格

每条包装规格定义：包装单位、基本单位数量、显示顺序、启用状态。右侧基本单位由 SKU 自动带入，数量必须为正整数。

同一 SKU 可存在多个包装规格，也允许同为“箱”但箱规不同。规格展示必须包含完整关系，例如：

- `200g/袋 10袋/箱 2kg/箱`
- `200g/袋 20袋/箱 4kg/箱`

生产报工不选择包装规格。仓储入库和销售出库允许混合箱规与散装余数，且：

`各包装规格换算的基本单位合计 + 散装基本单位 = 本次业务基本单位数量`

库存始终以 SKU 基本单位记账，包装组合是辅助物流明细。

## 4. 重量格式与精度

- kg 底层最多保留 6 位小数。
- g 展示最多保留 3 位小数。
- 盒、袋、件、箱等计数数量只允许整数。
- 质量和金额中间计算不提前四舍五入。
- 展示时删除无意义末尾零。
- `1000g = 1kg`、`1200g = 1.2kg`、`1250g = 1.25kg`。
- 默认质量展示为 kg；总览与半成品库存可临时查看 g，离开页面恢复 kg。

## 5. BOM

### 5.1 权威边界

BOM 是配料、辅料、包材、标准用量、配料出成率、配料所属工序和 BOM 版本的唯一来源。Workflow 只读引用，不重复维护。

BOM 配方允许使用 g/kg、kg/kg、百分比和每批固定用量等自然表达。库存扣减前统一换算为 kg。

### 5.2 理论用量与料头

配料出成率可选。对质量型配料：

- 理论投料量 = 标准净用量 ÷ 配料出成率
- 配料理论料头 = 理论投料量 - 标准净用量
- 工序理论料头 = 该工序质量型配料理论料头合计

包材不参与重量出成率。BOM 整体理论出成率由系统根据成品标准净重与质量型配料理论投料总重自动汇总并只读展示，不允许独立手填。

任一关键配料缺少出成率时，理论料头或整体理论出成率显示“数据不完整”，但 BOM 仍可保存。

## 6. Workflow

Workflow 仅维护工序顺序、半成品/成品流向、是否报工及 BOM 版本引用。

### 6.1 投入

- BOM 配料按工序自动带入并只读。
- 上游半成品自动带入。
- 原料和半成品的报工单位统一为 kg。

### 6.2 产出

- 半成品产出绑定正式半成品 SKU，单位固定为 kg。
- 成品产出绑定正式成品 SKU，单位继承 SKU 基本单位。
- 多产出分别继承各自 SKU 单位。

### 6.3 删除的旧能力

移除手工单位选择、包装换算下拉框、固定投入产出比例及 `box × 200 = g`、`case × 50 = box` 等英文换算行。

### 6.4 半成品历史出成率

半成品出成率不是配置项，而是只读累计指标：

- 统计主键：工厂 ID + 半成品 SKU ID
- 跨成品 SKU、Workflow 和 Workflow 版本
- 使用全部已完成、未撤销的有效历史批次
- 累计历史出成率 = 累计有效产出 kg ÷ 累计有效投入 kg

不得平均各批次百分比，不得人工修改。

## 7. BOM 与 Workflow 同步

新 BOM 版本生效后不得静默修改已发布 Workflow。系统生成待同步 Workflow 草稿，展示新增、删除、改量和改工序差异；管理员确认发布后仅影响后续计划。

计划创建时保存 SKU、BOM、Workflow 版本与单位快照。历史计划不重新解释。

## 8. 生产库与批次分摊

仓储出库将原料批次转入生产库。生产库余额按物料批次记账，但报工人员只填写物料投料总量，不选择来源批次。

正式提交时系统按生产库转入顺序自动分摊批次并保存分摊明细。分摊必须在事务内锁定余额，禁止并发超扣。

生产库可用量：

`累计仓储转入 - 已正式投料 - 已退回原料仓 ± 已审批盘点调整`

生产库不足时仅允许保存草稿，提示：

> 当前只能保存草稿：生产库可投料量不足。需要 {required}kg，可用 {available}kg，缺少 {shortage}kg，请联系仓管补料。

生产库结余可供后续报工使用；返回原料仓必须走退料流水。

## 9. 半成品报工

操作员填写实际投料 kg、实际产出 kg 和工时。正式小结后系统：

- 扣减生产库投料。
- 生成半成品批次。
- 半成品入库量 = 实际产出量。
- 半成品初始剩余量 = 实际产出量。
- 自动进入生产库供下一工序使用。
- 计算本批出成率和累计历史出成率。

## 10. 成品报工

每个成品 SKU 仅填写实际生产数量和留样数量。

- 入库数量 = 实际生产数量 - 留样数量
- 初始剩余数量 = 入库数量
- 成品重量 = 实际生产数量 × SKU 单位净重
- 入库重量 = 入库数量 × SKU 单位净重
- 多产出总成品重量 = 各成品重量之和
- 实际重量差异 = 实际投入重量 - 实际成品重量

BOM 理论料头与实际重量差异分开显示。未配置配料出成率时不计算理论料头。

删除报工中的领用、使用重量、手工单盒/单袋克重、手工成品重量、手工料头及包装规格选择。

## 11. 工时

每段工时填写开始日期时间、结束日期时间和人数。系统计算：

- 持续时长 = 结束时间 - 开始时间
- 人工工时 = 持续时长 × 人数
- 人工成本 = 人工工时 × 工序小时单价

支持跨天与多段工时；结束时间不得早于开始时间；人数必须为正整数。

## 12. 撤销小结与盘点

正式小结不可直接修改。24 小时内且逆转明细完整、下游未消耗时，通过现有“撤销小结”申请和审批逆转原料/半成品/成品库存，恢复工序行可编辑状态后重新小结。

撤销小结统一覆盖普通存货生产、客户自带原料加工和纯代工。

超过 24 小时、无法安全逆转或实物库存不一致时通过盘点调整库存。盘点不重写原生产记录。

## 13. 版本与迁移

迁移分为预览与执行两步。预览必须报告受影响 SKU、库存批次、数量、单价、总金额、Workflow、未开始计划及无法自动判断的记录。

原料/半成品从 g 转 kg 时：数量除以 1000、每 kg 单价乘以 1000、总金额保持不变。已完成业务单据保持原始快照。

固定包装成品根据已确认的 SKU 资料恢复盒、袋、件基本单位和标准净重；无法唯一判定的记录必须列入人工确认清单，不得猜测。

## 14. 验收标准

1. 固定包装成品可生成 `200g/袋 10袋/箱 2kg/箱`，不存在 `200g/克`。
2. Workflow 不再显示 box/case 或包装换算行。
3. 半成品单位为 kg，历史出成率按工厂+半成品 SKU 全历史加权计算。
4. 原料投料只填总量，系统按生产库转入顺序分摊批次。
5. 库存不足只能保存草稿，正式提交被阻止且提示缺口。
6. 半成品小结后自动进入生产库。
7. 成品仅填写实际生产与留样，入库、剩余和重量自动计算。
8. 多包装在仓储/销售支持混合箱规和散装余数。
9. 工时由开始、结束和人数自动计算。
10. 撤销小结和盘点边界保持一致，历史快照不被主数据修改。
11. F006 全链路验证通过后才进入其他租户的数据迁移确认。
