2. 数字指挥屏只讲 60 秒更新和来源状态。
3. 预测排班只讲明天、下周、下个月及一个门店时段。
4. 用“下周需要多少兼职”说明 FactBook 与 LLM 分工。

6. 用字段、频率、授权、沙箱和样板门店问题收尾。
