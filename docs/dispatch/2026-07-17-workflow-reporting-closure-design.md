# Workflow 多端口报工与库存结算闭环

## 目标

把已绑定到生产计划/批次的 Workflow 端口快照作为唯一报工契约，完成多投入、多产出、单位换算、库存过账、成本分摊和逐道追溯。不得由页面猜测工序单位、物料类别或产出 SKU。

## UX Flow Analysis（ux-flow 门控产出，不可删除）

### 用户画像

生产文员 / 报工操作员 —— 熟悉现场物料和称重，但不应理解数据库、成本模型或 Workflow 内部节点 ID；典型场景是在桌面端按生产计划逐道录入实际投入与产出。

### 用户旅程

| 步骤 | 用户看到 | 用户操作 | 期望结果 |
|---|---|---|---|
| 1 | 计划、批次、当前工序和 Workflow 版本 | 打开某道工序 | 只加载该工序端口允许的投入与产出 |
| 2 | 每个投入端口的物料、可用批次、余额、端口单位 | 选择批次或录入系统自动分摊的投入总量 | 不属于该端口或前置工序的物料不可选 |
| 3 | 本次生产日期、每个产出端口独立卡片 | 填写生产日期；按产出逐行填写开始/结束时间、人数、数量、副产数量和副产回收单价 | SKU 与单位由 Workflow 固定；不同产出的数量、时间和副产互不覆盖 |
| 4 | 单位换算、出成率和成本分摊预览 | 核对自动换算；混合维度时填写合计 100% 的分摊比例 | kg/g 等同维度自动换算；不可比单位不伪造换算 |
| 5 | 库存影响预览 | 点击“正式提交报工” | 显示投入分摊、产出事实以及“小结/结单时过账”的时点 |
| 6 | 成功结果和下一工序入口 | 继续下一道工序或留在当前工序续报 | 下一工序只出现 Workflow 连线允许的半成品/成品批次 |

### 摩擦点清单

| # | 摩擦点描述 | 严重程度 | 来源规则 |
|---|---|---|---|
| F1 | 一个总产量无法表达多产出，第二个产出没有数量关系 | HIGH | fool-proof Rule 1/2 |
| F2 | 用户可误选不属于当前端口的原料、半成品或成品批次 | HIGH | fool-proof Rule 1/3 |
| F3 | kg/g 可换算却重复填写比例；盒/kg 不可比却被系统猜测 | HIGH | fool-proof Rule 1 |
| F4 | 不清楚正式报工和库存小结各自改变什么 | HIGH | fool-proof Rule 2 |
| F5 | 连续点击造成重复投入分摊、重复产出或重复库存流水 | HIGH | fool-proof Rule 4 |
| F6 | 网络失败后已填的多个端口数据丢失或页面无下一动作 | MED | fool-proof Rule 5 / 内联 UX 错误恢复 |

### 每个摩擦点的设计回应

- F1 → 按 Workflow 输出端口固定渲染多行，SKU/单位只读，每行独立填写时间、人数、数量、副产和可选分摊权重；至少一个有效产出。
- F2 → 后端返回端口 SKU、物料类型和可用来源；前端只在对应端口内展示这些来源，后端再次按计划固定 Workflow 版本校验。
- F3 → 同维度数量统一换算到 canonical/base unit 后自动按数量分摊；混合维度或不可换算时显示成本比例，合计必须为 100%。
- F4 → 提交前展示库存影响：正式报工生成不可变投入分摊和产出事实，小结/结单才执行实际库存与成本过账。
- F5 → 每次正式提交生成稳定 idempotency key；后端以计划、工序、客户端行和 key 防重，重复请求返回原结果。
- F6 → 错误使用后端原始业务信息并保持表单；提供重试、保存草稿和返回计划三个下一动作。

## 领域规则

1. Workflow 激活后物化的 task/port 快照是报工真值；计划后续切换 Workflow 不改变已建批次。
2. 每条投入必须绑定输入端口；原料由生产库 FEFO 分摊，半成品/成品只能选择该输入端口 SKU 的可用批次。
3. 每条产出必须绑定输出端口；SKU、物料类型和单位必须与端口快照一致。
4. 一次报工共享生产日期和同一组投入，但产出按端口形成独立事实；每条产出独立记录时间、人数、数量、副产数量与副产回收单价，不得把总投入复制成每个产出的重复消耗。
5. 成本分摊快照随报工保存：同维度默认按 canonical 数量比例；混合维度要求显式权重，合计 100%。
6. 正式报工只生成投入分摊、产出及成本分摊事实；沿用现有小结/结单执行库存过账和可逆审计，不绕过既有 settlement gate。
7. 重试必须幂等；撤销/反结算必须按同一报工组整体逆转投入、产出和成本分摊。

## 验收场景

- 单入单出、多入单出、单入多出、多入多出均按端口保存。
- kg 与 g 自动换算并按标准质量分摊；盒与 kg 同时产出时必须填写权重。
- 第二个及后续产出都有独立数量、单位、批次和成本份额。
- 正式报工必须有生产日期；每条产出可独立记录起止时间、副产数量和副产回收单价。
- 非当前工序端口的物料、错误 SKU、错误单位和重复端口被后端拒绝。
- 重复提交不重复生成 MaterialConsumption、ProductionInputAllocation、产出库存或成本流水。
- 小结/结单只过账一次；失败事务不留下半套库存事实。
- 旧单产出和 legacy 非 Workflow 计划继续可用。
