# 柳杉门标签 QC 人工审核工作台 UX（2026-08-18）

## 目标

让工厂质检员在密集多盒照片中快速区分盒子、白标和彩标，明确记录“实物缺标”和“AI 漏框”，并减少重复框、文字遮挡和缩放定位造成的人工浪费。

## UX Flow Analysis

- 角色：工厂质检员，连续审核大量照片，优先依赖视觉规律和少量固定快捷键。
- 主路径：选照片 → 逐盒核对白标/彩标 → 修正框 → 确认整图 → 下一张 → 提交整单。
- 高频错误：把实物缺标误画成一个假框；把 AI 漏框误记为缺标；叠画 AI 参考框与已接纳框；密集文字遮挡；缩放后目标离开鼠标位置。
- 降低负担：照片内只显示纯色框和横向辅助线，详细文字留在右侧；三个类别可独立显隐；切换保留草稿；危险的整盒删除仍需确认。

## 缺标与漏框规则

| 原图事实 | 人工操作 | 训练含义 |
|---|---|---|
| 实物没有白标/彩标 | 选“实物缺标”，不画标签框 | 缺标真值 |
| 实物有标签，但 AI 没画框 | 点“补白标框/补彩标框”并修正位置 | 标签存在的人工框 |
| 被遮挡或无法判断 | 选“看不清” | 不作为缺标真值 |
| 盒子也漏了 | 先补完整可判断的盒子框，再判断标签 | 盒子与标签均为人工真值 |

选择“实物缺标”时，现有同类 AI 标签框会被移除并记录为拒绝的 AI 提议；不得生成不存在的标签框。

## 视觉与交互

- 盒子：深青色实线框；白标：深红色实线框；彩标：深紫色实线框。
- 照片内默认不显示框上文字，避免密集遮挡；类别和状态在右侧面板显示。
- `Q / W / E` 分别显示或隐藏盒子、白标、彩标；开关同时控制最终框和对应横向辅助线。
- 白标和彩标按横排生成醒目的纯色实线辅助线，不生成纵线。
- 鼠标滚轮以指针位置为中心缩放；`A` 上一张，`Space / Enter` 确认并下一张，`Backspace` 删除当前框。
- 切换照片保留本批次内存草稿；只有提交整单后才写入服务器，界面不得把草稿保留表述成服务端已保存。

## 重复框规则

- 不再同时叠画同一个 AI 参考框和已接纳的可编辑最终框。
- 对同类别、覆盖较高的 AI 提议框按连通组处理，三四个高度重叠框也作为一组，只保留面积更大、边界更完整的候选。
- 相邻框和不同类别框不得自动合并；人工已审核数据不得被自动去重改写。
