# 六扇门手机号白名单开户

## 目标

工厂超级管理员在 Web 或 RN 白名单模块中输入手机号、姓名与工厂角色，创建本工厂的开户邀请。被邀请人使用同一手机号完成注册；登录账号固定为手机号，最终工厂和角色只由服务端白名单决定。

## 用户流程

1. 工厂超级管理员打开“账号开通”。
2. 输入手机号、姓名并选择允许的工厂角色。
3. 服务端校验当前管理员、目标工厂、手机号唯一性和角色授权范围。
4. 被邀请人选择“手机号注册”，输入同一手机号并完成两阶段注册。
5. 注册第二阶段再次读取并锁定白名单；客户端提交的用户名、工厂或角色不能覆盖邀请。
6. 注册完成后，白名单标记为已使用，并返回手机号登录账号和受邀角色。

## 权限与防呆

- 仅工厂超级管理员可创建本工厂邀请，不扩大平台管理员或普通员工权限。
- 手机号必须规范化后匹配；跨工厂白名单、过期或已使用邀请均 fail-closed。
- 角色只能来自服务端允许列表；客户端角色仅用于旧接口兼容，不具备授权效力。
- 旧的无角色白名单保持未激活兼容，不自动赋予高权限角色。
- 重复提交返回现有邀请，不创建重复账号或重复消耗白名单。

## 前后端契约

- 白名单新增 `invitedRole`，创建、列表和注册预检均返回同一字段。
- 注册账号 `username` 固定为规范化手机号。
- Web/RN 的角色选项展示使用中文名称，提交使用后端角色代码。
- 错误信息说明“发生了什么 + 下一步怎么做”，并保留已填写内容。

## 验收

- 真实 JPA Context 验证 Repository 查询可启动。
- Java 覆盖邀请创建、手机号注册、跨工厂与客户端提权拒绝。
- RN 覆盖预检、两阶段注册、角色和手机号字段契约。
- Web 覆盖账号创建表单、角色选项、列表回显和 API payload。
- 只合并代码，不部署，不创建或修改生产账号与白名单。
