# Workflow → BOM 上下文、工序辅料单位与多输出 BOM 修复

## 目标

1. Workflow 的“配置 BOM”快捷入口保留目标输出 SKU 上下文，BOM 页面加载后自动选中正确 SKU。
2. 一个 Workflow 有多个终端成品时，每个终端 SKU 独立维护自己的 BOM；同一 SKU 重复进入复用同一草稿，不重复创建。
3. 生产计划固定精确 Workflow 修订和所选输出集合；报工按该输出集合解析对应 BOM，共享投入规则只计算一次，各终端专属规则归属自己的 SKU。
4. 工序辅料直接使用 Workflow 产出端口所绑定 SKU 的单位作为基准；`只`、`袋` 和自定义单位无需进入硬编码白名单。
5. 保留“转换率”标签，只移除 BOM 页面顶部灰色说明提示。

## UX Flow Analysis（ux-flow 门控产出，不可删除）

### 用户画像

生产配置管理员与现场报工人员 — 管理员理解 SKU/BOM，但不应记忆内部 ID；报工人员只关心本次允许投入、实际投入与实际产出，不应理解 BOM Family 或 Workflow revision 等技术概念。

### 用户旅程

| 步骤 | 用户看到 | 用户操作 | 期望结果 |
|------|---------|---------|---------|
| 1 | Workflow 中当前成品及“配置 BOM”提示 | 点击快捷入口 | 进入 BOM 页并自动选中当前成品 SKU |
| 2 | 多输出 Workflow 的成品节点 | 从具体成品入口进入，或从通用入口进入 | 具体入口精确选中该 SKU；通用入口稳定选中第一个终端 SKU并可切换 |
| 3 | 当前 SKU 的 BOM 版本和工序辅料 | 配置原料、包材、辅料 | 每个成品 SKU 保存自己的 BOM；重复进入不产生重复草稿 |
| 4 | 工序辅料投入基准 | 按“每 1只/1袋/1自定义单位产出”填写 | 不因单位不在硬编码列表而只读；仅跨单位换算时要求换算关系 |
| 5 | 生产计划与逐工序报工 | 选择实际投入/产出并正式报工 | 系统按固定 Workflow 输出集合读取对应 BOM，联合计算且共享规则不重复 |

### 摩擦点清单

| # | 摩擦点描述 | 严重程度 | 来源规则 |
|---|-----------|---------|---------|
| F1 | 快捷跳转丢失 SKU，BOM 页显示无关产品 | HIGH | fool-proof Rule 2 |
| F2 | 多输出未指定目标时刷新后可能漂移 | HIGH | fool-proof Rule 2 / 稳定默认 |
| F3 | 合法的 `只/袋/自定义单位` 被判定不支持 | HIGH | fool-proof Rule 1 |
| F4 | 同一 SKU 重复创建 BOM 草稿 | HIGH | fool-proof Rule 4 |
| F5 | 多输出报工只拿到一个 BOM 或重复计算共享投入 | HIGH | fool-proof Rule 1 |
| F6 | BOM 页灰色说明提示占空间且干扰主任务 | LOW | 信息密度 |

### 每个摩擦点的设计回应

- F1 → 路由携带 `productTypeId`，页面在产品列表异步加载后再应用目标选择；禁止被默认产品覆盖。
- F2 → 未指定目标时按终端 SKU 稳定排序选择第一个，不使用运行时随机数；用户仍可切换。
- F3 → 基准身份采用“产出 SKU + 原始单位快照”，非空单位即可作为每单位辅料基准；只有换算才调用单位契约。
- F4 → 服务端以工厂、SKU、状态和固定 Workflow 修订复用现有草稿；并发场景不得生成同 SKU 同版本双草稿。
- F5 → 计划按精确输出集合解析全部对应 BOM；共享规则按稳定共享身份去重，终端专属规则按 SKU 保留。
- F6 → 删除灰色说明块，不删除“转换率”标签、路由、数据或后端能力。

## 确定行为

### Workflow → BOM

- 具体 SKU 的快捷入口必须传 `productTypeId`；如果带 `workflowId`/`workflowRevisionId`，只作一致性校验，不允许覆盖 SKU。
- BOM 页面在 query、产品列表和当前选择三者之间使用明确优先级：有效 query SKU > 当前仍有效选择 > 稳定默认 SKU。
- query SKU 不属于当前工厂或不是该 Workflow 终端输出时，显示可操作错误，不静默切换到无关产品。

### 多输出 BOM 与报工

- 同一 Workflow 的两个终端 SKU 对应两个 Output BOM；共享 Workflow revision 相同，目标终端节点不同。
- 生产计划固定所选输出集合及每个输出对应的 BOM revision。
- 报工允许本次只产出其中一个或多个；投入候选来自固定 BOM 主料/替代料和库存批次交集。
- 共享投入、共享辅料、共享人工和共享制费只能汇总一次；SKU 专属包装和终端工序成本只进入对应 SKU。
- 缺少某个计划输出的有效 BOM 时，在计划或报工写入前阻止并列出 SKU，不允许只取第一个 BOM 静默继续。

### 单位

- 对 `只`、`袋`、`bag` 或任何已绑定 SKU 的非空单位，标准辅料基准为 `1 <原单位>`。
- `kg` 仍显示为 `1 kg`；`g` 可保留现有 `1000 g` 基准兼容。
- 单位字符串仅用于同单位基准时不做维度猜测；跨单位计算必须使用明确换算契约，缺失时只阻止该换算，不应让整个辅料配置只读。

## 验收

- 从干式熟成鸡 400g Workflow 快捷入口进入 BOM 后自动选中 400g SKU，不显示其他产品。
- 多输出 Workflow 的两个具体成品入口分别选中各自 SKU；通用入口默认选择稳定且刷新不漂移。
- `只`、`袋`、`bag` 和测试自定义单位的工序辅料可编辑并显示正确基准。
- 同 SKU 重复快捷进入不新增草稿；两个不同终端 SKU 各有一个 BOM。
- 计划固定两个输出后，报工解析两个对应 BOM；只报其中一个产出也合法，共享规则不重复计入。
- “转换率”标签仍存在，灰色说明提示不存在。
- Java/Web 目标测试、Web typecheck/build、只读 UI/代码审查和 `git diff --check` 通过；不写生产数据、不部署。
