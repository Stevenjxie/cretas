# 无订单入库申请与客户专属库存生产

## 业务边界

- 无订单入库申请是仓储页面里的运营来源单，不是销售订单，也不是库存单据。发起时选择客户来料、赠予或其他原因，可选填写预计到达、联系人和说明；客户来料必须选择归属客户。
- 客户来料收货后生成客户所有库存；赠予和其他原因收货后生成公司所有库存，即使选填了关联客户也不改变归属。
- 只有仓储确认现场实物后，系统才按实际原料、数量和仓库生成客户所有原料库存；当前不增加来料质检。
- 生产仍只有“销售订单生产”和“库存生产”两类。库存生产新增库存归属：公司库存或客户专属库存；归属客户仅在客户专属库存时必填。
- 客户专属库存生产只领用同一客户且尚未绑定销售订单的原料，产出为同一客户所有、尚未绑定销售订单的成品。
- 正式销售订单选择“使用客户已有库存”后，只能预留并发出同一客户名下、尚未绑定其他订单的成品；不足时不得回退占用公司库存。
- 原料收货前不做质检；既有生产成品照片质检、报工和成品入库流程保持不变。

## 完整操作流程

1. 运营在“仓储 → 原料 / 物料入库与批次”页发起“无订单入库”，选择“客户来料”及归属客户，不填写原料、数量和仓库。
2. 仓管在同页统一待收货区看到“客户来料”申请，现场选择实际原料、实收数量、库存单位和实际仓库。
3. 仓管确认后生成客户所有原料批次；若还有下一车则保留申请，全部到齐则结束申请。赠予或其他原因走同一收货动作，但生成公司所有库存。
4. 生产创建“库存生产”，选择“客户专属库存”并选择归属客户；计划数量可暂不填写。
5. 领料、报工、小结、成品照片质检和成品入库沿用现有流程；系统只允许使用同客户未绑定订单的原料，并产出同客户未绑定订单的成品。
6. 正式销售订单选择“代加工 + 客户自带原料 + 使用客户已有库存”。财审后系统按同客户未绑定成品建立订单预留台账，不改写原批次生产来源。
7. 发货选批和扣减只允许使用该销售订单的有效预留；取消订单释放预留。库存不足时明确提示，不占用公司库存，也不自动创建公司生产计划。

## 权限

| 角色 | 无订单入库申请 | 仓储实际收货 | 库存/生产/销售 | 质检/财务/系统 |
|---|---|---|---|---|
| 运营协调员 | 在仓储页读写申请、可取消未收货申请 | 只读，不生成库存 | 只读 | 无权限 |
| 仓管 | 只读申请，不可发起/取消 | 读写，现场确认后生成库存 | 沿用既有仓储权限 | 沿用既有权限 |
| 工厂/平台/权限管理员 | 读写 | 沿用管理员权限 | 沿用管理员权限 | 沿用管理员权限 |

## UX Flow Analysis（ux-flow 门控产出，不可删除）

### 角色与主要屏幕

- 运营协调员：Web“仓储 → 原料 / 物料入库与批次”。主动作只有“发起无订单入库”，表单不出现原料、数量、仓库或质检字段，避免运营猜测现场事实。
- 仓管：同一页面的统一待收货区。任务来源明确标为客户来料、赠予或其他无订单入库；确认弹窗固定显示实际库存归属，并要求现场填写实际原料、数量和仓库。
- 生产人员：RN 生产计划创建弹窗。先选择“基于库存”，再选择“公司库存/客户专属库存”；只有客户专属库存显示必填客户。
- 销售人员：Web 销售订单。只有“代加工 + 客户自带原料”才显示“本订单后续送料/使用客户已有库存”。

### 状态、反馈与恢复

- 申请状态为待收货、部分收货、已完成、已取消；已有收货事实后不可取消，以保留库存来源追溯。
- 仓储确认前用二次核对展示客户、原料、数量、单位和“客户所有”归属；确认失败不关闭弹窗，幂等键防止重复入库。
- 多车到货由“结束申请/保留待办”显式选择，不靠系统猜测剩余数量。
- 客户专属生产缺客户、跨客户领料或误用已绑定订单的原料时，服务端阻断并指出应选择的客户库存范围。
- 销售订单库存不足时保留未满足状态并给出补产/核对客户库存的下一步，不静默改用公司库存。

### 低技术素养操作约束

- 页面用“无订单入库”“核实并入库”“客户专属库存”等业务词，不要求用户理解数据库归属字段。
- 默认公司库存，降低现有操作路径变化；客户专属库存必须由用户主动选择。
- 关键选择使用分段按钮或单选按钮，主操作保持单一；不可执行动作通过隐藏、禁用或明确错误阻断。
- 当前流程不展示来料质检入口；成品照片质检仍在原有生产后流程出现。
