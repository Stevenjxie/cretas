# M67 和牛牛腱 — 成本核算数据采集方案 & 系统 vs Excel 对比

> 面向客户(六膳门)。回答三件事：①系统要客户提供什么数据、怎么提供 ②滚揉注水/中间工序怎么处理 ③系统比现行 Excel(v5.0)强在哪（用真实「熟制0614」那锅验证）。

---

## 一、业态确认：无订单 / 备货生产 → 按「日期(批次)」核算

客户是**无订单、自主排产、半成品备货**，最终份数事前未知。所以成本核算**不挂销售订单**，而是：

- 出成率/成本 **按生产批次**算；
- 汇总 **按日期/产品+时间区间**（"这天/这个月这个品：总投入 vs 总产出 → 出成率；总成本 ÷ 总产出 → 单位成本"）。

> 注：客户现行 Excel 汇总页的「订单批次」其实就是**日期**——本质已是按日期核算，系统与之一致。

---

## 二、需要客户提供的数据

### A. 必须称/记的 3 个点（最少集，够算核心 3 数 + 混批精确）

| # | 采集点 | 记什么 | 谁/在哪 |
|---|---|---|---|
| 1 | **领料** | 用了哪个原料批次、多少 kg | 操作员 / 手机报工 |
| 2 | **领用半成品（混锅，关键）** | 这一锅用了哪几批半成品、各多少 kg（如 焯水0613 78kg + 焯水0614 22kg） | 操作员 / 手机报工 |
| 3 | **产出** | 成品多少盒、工时、人数 | 操作员 / 手机报工 |

> 这 3 个点之外，**中间工序(修油/滚揉/焯水)的重量可以不称**——核心 3 数（总出成率 / 单盒成本 / 人工）和混批精确成本**都不依赖中间重量**（原因见第四节）。

### B. 选称（只为「看哪道缩水多」才需要）

- 逐道出成率：要该道的**投入 + 产出**都称。不称就没有这道的逐道率，但**不影响**核心成本/总出成率。

### C. 一次性配置（管理员后台设一次，之后不动；操作员不碰）

- 工序顺序（修油→滚揉→焯水→熟制→气调→包装）
- 单盒克重（0.1kg）、员工时薪（26 元/h）、装框人工（0.08 元/盒）
- 辅料单价（卤汤/腌料…）、**原料采购单价**
- 每道工序默认成本类别（原料/调料/辅料/包装）—— 配一次，报工自动带出，**操作员不手填会计类别（防呆）**

> ⚠️ 客户现行 Excel **没有算原料成本**（只算了出成率+人工+调料）。要算"单盒总成本"必须补**原料采购单价**——这是系统能补、Excel 缺的一块。

## 三、滚揉注水 & 中间工序，怎么处理

- **注水让滚揉「出成率 >100%」（v5.0 实测 119.9%）**——系统**不连乘**，直接用「成品总重 ÷ 原料领料总重」算总出成率，注水不会把账算虚（成品里本就含吸收的水/料）。滚揉那道的 119.9% 系统照样能显示，标注"注水增重正常"，但不进总账。
- **注水加的料**：若只是水→不计成本；若加了腌料/盐水（要钱）→在滚揉道记一笔辅料（量+单价），系统归调料/辅料。**这是客户现行 Excel 漏算的成本。**

---

## 四、为什么「混批精确成本」不依赖中间重量（关键原理）

「成本」和「出成率分解」是两回事：

- **某批半成品的成本 = 它的领料钱 + 它身上的人工钱**——跟它中途缩到多少 kg **无关**。
- 混锅时记「各批领用量(78 / 22)」+ 每批自带成本 → 按各自**真实成本**拆，**不糊重量平均**。
- 中间重量只决定「逐道出成率」，不决定「钱怎么分」。

> 所以省掉中间称重，单盒成本与混批拆分照样精确。

## 五、系统 vs 现行 Excel —— 用真实「熟制0614」那锅验证

**真实场景**：熟制0614 这一锅 = **焯水0613 78kg（原料0612 链）+ 焯水0614 22kg（原料0613 链）**，两批来自不同原料、单价不同。

| 维度 | 现行 Excel v5.0 | 系统（实测，DEMO 环境同锅） |
|---|---|---|
| 混批两条链 | ❌ 主算表 `XLOOKUP` 只取到 **原料0612(78kg)**，**原料0613 的 22kg 被丢掉** | ✅ **两条链都在**：焯水0613 78kg=¥7170 + 焯水0614 22kg=¥3740 |
| 成本分摊 | 只能"加权平均"（且实际漏了一条链） | ✅ 按各自成本：**重量占比 78:22，但成本占比 65.7% : 34.3%**（单价不同） |
| 出成率 | 各道**连乘**反推，注水(119.9%)致原料倒推虚高 | ✅ **成品÷原料**直接算（58.2%），注水不影响 |
| 原料成本 | ❌ 未计算（表里无原料单价） | ✅ ¥10910（沿血缘回溯各批 traced 成本） |
| 单盒成本 | 仅 人工 0.61 + 调料 0.24（无原料/包装合计） | ✅ **¥7.89/盒**（原料6.11+人工0.75+调料0.55+包装0.49），另出净成本¥7.80、可售¥7.82 |
| 副产/留样/包装明细/辅料分摊 | 无 | ✅ 肥油回收、留样可售、包装4拆(膜/气体/标签/其他)、辅料按锅平摊 |
| 稳定性 | `#N/A`/`#DIV/0!` 一断全断（6-17 后整列报错） | ✅ 缺数据诚实显示"待录入"，不连锁崩 |

> **一句话**：Excel 因为 `XLOOKUP` 一次只能查一条链，混批必丢料（v5.0 自己就丢了 22kg）；系统有真血缘账本，一对多不丢、按各批真实成本精确拆。

## 六、采集方式（落地）

- **手机报工（操作员，每批）**：领料 → 领用半成品(混锅各批量) → 产出(盒数+工时+人数)。中间工序可设"免报"。
- **后台配置（管理员，一次）**：工序链 + 单盒克重/时薪/装框费 + 辅料/原料单价 + 工序默认成本类别。
- **系统自动出（按日期/批次/区间）**：出成率、单盒成本（原料+人工+调料+包装）、单盒人工、混批拆分表 + 溯源图。
