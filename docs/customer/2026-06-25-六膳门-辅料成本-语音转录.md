## 关键口径要点（从转录提炼）

1. **锚点二选一**：辅料无法在中间工序精确取，只能锚定两端——
   - 从源头投料（投 100kg 料 → 对应固定辅料量）
   - 或从成品产出（产了 X 成品 → 对应固定辅料量）
   - Steve 拍板（本次）：**两个锚点都做，核对结单时对账**。
2. **辅料单价 = 每工序固定 元/kg，离线按配方预先算好**，系统不实时 BOM 计算。
   例：滚揉调料 16.60/8.68 = 1.91 元/kg；预煮 102.03/140 = 0.73 元/kg。
3. **倒推**：份数 + 出成率 → 倒推各阶段 kg → ×各工序辅料单价 → Σ总额 → ÷份数 = 分摊费用/份。
   （张权例：生产 1090 份，熟制出成率 87%，倒推一共用 150kg 料，×单价 = 总额，÷1090 = 每份的钱。）
4. **只要总量**：不必每工序向用户报辅料投入，知道一个总量即可。
5. **比例固定**：固定公斤数原料对应固定辅料；批次出成率波动导致的辅料偏差极小，忽略。
6. **工序无辅料不能崩**：产品有熟制工序但没配辅料 → 算 0，不报错。工序是通用模块，产品非标、来去频繁，不能一品一维护。
7. **主辅料计算逻辑相同**："先跑主料"只因辅料项多手算烦，非技术分步——同一引擎跑主+辅。
