# 成品出厂核算系统 — 演示说明（M67 卤牛肉）

> 把您现在用 Excel 手工做的「全链路出成率 + 单盒成本 + 人工成本」核算，做成**系统自动版**——自动算、算得准、不会断。

---

## 一、解决您 3 个核心需求

| 核心数 | 系统自动算出 | 说明 |
|---|---|---|
| **出成率** | **58.2%** | 成品净重 ÷ 原料投入，逐道工序自动连乘 |
| **单盒成本** | **¥8.32 / 盒** | 原料 + 人工 + 调料 + 包装，自动拆解 |
| **人工成本** | **¥0.75 / 盒** | 各道工序工时 × 工价，自动分摊到每盒 |

（数据取自您 M67 卤牛肉一批：1787 盒）

---

## 二、系统一屏呈现（截图见附件）

1. **顶部 4 张卡**：整批出成率 58.2% · 单盒成本 ¥8.32 · 单盒人工 ¥0.75 · 产出 1787 盒
2. **逐道出成率**：修油 90.7% → 滚揉 119.9%（注水增重自动识别）→ 焯水 72.8% → 熟制 74% → 气调 99.4% → 包装 100%；超范围自动标红预警
3. **单盒成本拆解**：原料 79% ¥6.53 / 人工 9% ¥0.75 / 调料 7% ¥0.55 / 包装 6% ¥0.49
4. **批次溯源图**：成品 ← 气调 ← 熟制 ← 焯水 ← 滚揉 ← 修油 ← 原料，宽度=物料重量，损耗一目了然

## 三、比 Excel 强在哪

| | Excel 现状 | 系统版 |
|---|---|---|
| 录入 | 必须按 修油→…→汇总 严格顺序手填，批次号不能改 | 车间报工后**自动汇总**，无需手工 |
| 健壮性 | 一个空行/缺数 → `#DIV/0!`/`#N/A`，**整列往下全断** | 系统兜底，**不会断** |
| 多锅混批 | 一锅熟制用多批焯水时，公式只认一条链 → **算不准，只能糊平均** | 按**实际投料量**逐批溯源、精确归集成本 |
| 实时性 | 会计夜里整表 | 老板手机/电脑**实时看**每盒成本 |
