## 2. 单元测试清单（**TDD：先写这些断言，全用客户/审计的真实数字**）

> 每条都是客户那版公式会**算错**的场景。测试通过 = 5 个硬伤都堵住。

### TC-1 人工守恒（硬伤①）
- 单链：修油产出90/滚揉85/焯水80，人工 240/360/200；订单从焯水取 50kg。
- **断言**：订单修油分摊 = `150.00`（**不是** 客户公式的 133.33）；滚揉 = `225.00`；焯水 = `125.00`。
- **守恒断言**：焯水全 80kg 被多订单消耗时，`Σ各订单修油分摊 == 240.00`（无泄漏）。

### TC-2 一单多熟制盒数去重（硬伤②）
- QD-300 = SZ-A 20kg + SZ-B 10kg，订单产出 200盒/25kg，总成本 ¥4000。
- **断言**：盒数 = `200`（**不是** 400）；每盒成本 = `¥20.00`（不是 ¥10）。
- 扩展：3 个熟制批次时盒数仍 = `200`。

### TC-3 支链跳工序反推原料（硬伤③）
- A链：原料A 100kg→修油90→滚揉90→焯水50→喂SZ 50kg；B链(**跳焯水**)：原料B 20kg→修油19→滚揉(GR-002)10kg→直喂SZ；SZ 60→30；QD 30→25kg。
- **断言**：反推原料总量 = `120.0kg`（**不是** 客户链式连乘的 129.6kg）；A料=100、B料=20 分列。
- 注水变体（B链滚揉率2.0）：断言仍 = 真实投入，不出现 +24% 高估。

### TC-4 工序间外购掺入（硬伤④）
- 修油 原料出库100→产出90；修油后掺**外购半成品 20kg**→滚揉投入110→…→成品25kg。
- **断言**：自产原料 = `100kg`；外购半成品 = `20kg`**单列**（不被算进"原料"口径 → 不出现 +22% 虚增）。

### TC-5 混批异质成本用实测 split（硬伤⑤）
- SZ 投入 A链50kg(累积8元/kg) + B链10kg(30元/kg)，逐源 quantity 实测。
- **断言**：混合单位成本 = `11.67元/kg`（`(50×8+10×30)/60`，**不是** 按比例估的 12.84）。
- 数据缺失分支：若某混料节点只有总量无逐源量 → 断言返回值带 `precisionWarning` 含 `误差≈Δsplit×(costB−costA)`。

### TC-6 综合出成率 = Σ产出/Σ投入（保留客户正确部分 + 防回归成"对率加权"）
- 熟制0614 = 焯水0613 78kg(投入156kg) + 焯水0614 22kg(投入27.5kg)。
- **断言**：综合焯水率 = `54.5%`（`100/183.5`，**不是** 按 78:22 对率加权的 56.6%）。

### TC-7 干净串行守恒（happy path 不回归）
- 无跳工序、无外购、无混批的纯串行链。
- **断言**：逐路径物料平衡反推原料 == 真实首端投入量（误差 0）；与客户链式连乘在此场景结果一致（证明只在异常拓扑才分叉）。
