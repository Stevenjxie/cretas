# 第二阶段.5：生产计划财务审批（财审）

## 📍 节点说明

**触发时机**：销售订单确认后，创建生产计划前需要财务审批。

## 🎬 操作步骤（Web-Admin）

**财务人员操作**：
1. 导航：「生产管理」→ 「生产计划」→ 「待审批」
2. 找到待审批计划（状态：PENDING_APPROVAL）
3. 查看计划详情：
   - 产品名称、计划数量
   - 预估成本（原料 + 人工 + 制造费用）
   - 对应销售订单号
4. 审批操作：
   - 点击「审批通过」→ 计划状态变为 APPROVED
   - 或「驳回」→ 填写驳回原因 → 退回创建人修改
5. 审批通过后，生产管理员才可执行「转为批次」

**注意事项**：
- 未经财审的计划无法转批次（系统拦截）
- 驳回后原计划可修改后重新提交审批

#### 出成率超限时的 UI 交互

当产出量超过允许上限时，系统即时响应：

**RN App 表现**：
1. 实时校验：输入产出量时立即计算出成率
2. 超限时：
   - 产出量输入框变红
   - 显示红色提示文字：「超出允许范围！当前出成率 X%，最大允许 X%（上限 Xkg）」
   - 「提交」按钮变灰 + disabled，无法点击
3. 修改产出量回到范围内 → 提示消失，按钮重新可用

**允许范围计算**：
- 下限 = 投入量 × 工序最低出成率（standard_yield_min）
- 上限 = 投入量 × 工序最高出成率（standard_yield_max）
- 例：道4（二次滚揉保水）投入 1006kg，standard_yield_max=1.5 → 上限 1509kg

**常见情况**：
- 道4 保水：出成率 >100% 正常（注水增重），上限 150%
- 道5 焯水：出成率 40-60%，低于 40% 或高于 80% 触发警告
- 首道（解冻）：无强制上限时（未配置）系统不拦截

## 快速排错手册

| 问题描述 | 可能原因 | 解决方法 |
|---------|---------|---------|
| 无法报工（按钮灰）| 上道未完成 | 先完成上道出成率报工，系统自动解锁 |
| 出成率超收警告 ⚠️ | 产出 > 投入×上限 | 确认数字无误，若工艺要求则联系工厂长调整配置 |
| WIP 可领用量为 0 | 上道未提交产出 | 检查上道完工报工是否已「确认完工」 |
| 跳过了某道工序 | 误操作/工序流程变更 | 检查批次详情工序列表，手动补报或联系计划员 |
| 完工后无 FG 记录 | 道 10 未完工或未入库 | 确认最后一道已完工报工，点「完工入库」→ FG 自动建库 |
| 出货时库存不足 | FG 库存已被占用/失效 | 检查 finished_goods_batches 表 available 数量是否 > 0 |
| 跨天报工时段不连续 | SEGMENT 阶段支持跨天 | 正常工艺，系统自动合并同批次同道所有时段 |
| 称重数值误差 | 电子秤未校准/APP 输入 | 用标准砝码校秤；APP 输入后点"确认"前核查一次 |
| 照片上传失败 | 网络超时/OSS 服务异常 | 检查网络信号；若 OSS 挂载，可离线拍照后补传 |
| 显示「权限不足」 | 角色不匹配 | 工序长应为"操作工/工序长"角色，联系工厂长授权 |
